# APZHUB APZ TCMS — Engineering Intelligence User Guide (APZTCMS-022)

## What it is

Engineering Intelligence is a **read-only** Testing workspace that presents existing quality analytics: scores, health, trends, risk, benchmarks, and historical snapshots.

It does **not** invent new analytics, run AI, or change certification/release decisions.

## How to open

1. Open the Testing activity.
2. Select **Engineering Intelligence** in the sidebar.
3. Use panel tabs to switch views.

## Common actions

- **Refresh** — reload current data from the platform API.
- **Release filter** — UI filter label for comparison context (presentation).
- **Compare Baselines** — request a benchmark comparison from existing services.
- **Open Certification / Coverage / Evidence / Pipeline / Release** — navigate to related Testing sections.

## Permissions

You need at least one of: `engineering.view`, `analytics.view`, `quality.view` (or matching wildcards). If you see “unavailable”, ask an administrator.

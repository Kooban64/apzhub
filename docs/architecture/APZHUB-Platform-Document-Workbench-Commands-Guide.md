# APZHUB Platform Document Workbench — Commands Guide

**Milestone:** APZDOCS-005

## Toolbar commands

| Command | Behaviour |
|---------|-----------|
| Refresh | Refetch active React Query caches |
| View Metadata | Detail panel — metadata + safe storage/checksum fields |
| View Versions | Detail panel — version table |
| View Relationships | Detail panel — read-only context |
| View Retention | Detail panel — retention ID |
| View Audit | Detail panel — audit rows |
| Open Folder | Detail panel — folder ID |
| Open Collection | Detail panel — collection ID |
| Inspect Diagnostics | Detail panel / diagnostics section |
| Copy Document ID | Clipboard write of selected document id |
| Copy Version ID | Clipboard write of selected version id |

## Palette

Manifest action `platform.documents.navigate` — “Go to Documents” (`workbench-bridge:workbench.navigation.reveal`).

## Exclusions

No upload, download, delete, edit, preview, or binary commands.

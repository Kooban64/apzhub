# POPIA Assessment

| Topic               | Architecture stance                                                          |
| ------------------- | ---------------------------------------------------------------------------- |
| Recipient data      | Identity-resolved; minimise payload                                          |
| Contact information | Not required for in-app; external provider later under ADR-0074 + COMP-001   |
| Purpose limitation  | Transactional/attention delivery only                                        |
| Retention           | Operational retention configurable; legal retention approval separate        |
| Deletion/correction | Supportable via admin/data subject process — not automatic full DSAR product |
| Provider processing | Future external enablement requires formal compliance approval               |
| Cross-border        | Document if provider processes outside RSA                                   |

**Does not claim formal legal compliance.** External delivery remains gated.

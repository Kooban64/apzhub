## Direction

1. Stream 1 (public website → marketplace → purchase → PayFast → provisioning → invite → work) is the **sole active UI/UX execution stream** until its Definition of Done is met.
2. Authenticated **APZQEP / APZPEN / APZPRD application** remodel (Streams 2–4) is **blocked** until Stream 1 completes.
3. Admin/staff shell consistency is a **later alignment concern** — get the commercial + product design language right first; apply consistently across personas.
4. PayFast: custom / onsite / subscriptions / tokenisation; APZ never stores raw cards; sandbox before live; ITN server verification mandatory.
5. Workbench polish already delivered (production runtime, Activity Bar / Sidebar Lucide icons) remains in force; deferred app remodel ships (Time/Support/Projects/Knowledge deep UX) wait for Stream 1.

## Does not authorise

Unbounded redesign of Production Ready QEP/PEN product apps during Stream 1.

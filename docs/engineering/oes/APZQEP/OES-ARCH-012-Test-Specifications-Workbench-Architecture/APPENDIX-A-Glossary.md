# APPENDIX A — Glossary

| Term                       | Definition                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| **Test Specification**     | Approved (or in-progress) engineering intent of testing — not a Case, Execution, or Verification |
| **Authoritative**          | Latest Approved Specification version intended for downstream consumers (`isAuthoritative`)      |
| **availableActions**       | Server-computed list of commands the caller may invoke for a Specification                       |
| **Explorer**               | List-first inventory surface                                                                     |
| **Inspector**              | Detail + action surface for the selected Specification                                           |
| **Review queue**           | Navigation filter for `under_review` work — not a Domain entity                                  |
| **Relationship**           | Reference from a Specification to another artefact; not ownership                                |
| **Supersession**           | Approved Specification replaced by a successor; predecessor becomes `superseded`                 |
| **Governed unavailable**   | UX state when a linked capability/artefact is absent or forbidden — no fake data                 |
| **Workbench Architecture** | Presentation design OES — excludes React/Next implementation                                     |
| **OES**                    | Owner Engineering Specification                                                                  |
| **COMPLETE.md**            | Assembled authoritative pack for Owner Review                                                    |

## END OF APPENDIX A

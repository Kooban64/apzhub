## Purpose

OES-002 continues to govern Architecture / Domain / Infrastructure / Workbench reviews and **ECR**.

This addendum adds a review class for **Engineering Wave Review** between Waves:

| Review class            | When                                | Outcome                  |
| ----------------------- | ----------------------------------- | ------------------------ |
| Engineering Wave Review | After each Wave reaches IMPLEMENTED | ACCEPT / RETURN / REJECT |

ECR remains mandatory before overall Engineering Owner Acceptance (OES-002 §10A). Wave Acceptance does **not** replace ECR.

## Build Contract compliance

Wave Review **SHALL** verify Engineering Build Contract compliance (checklist in Wave completion report).

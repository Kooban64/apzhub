## Change summary

Adds **Engineering Completion Review (ECR)** as a mandatory review class immediately before Owner Acceptance of Engineering programmes.

ECR verifies Work Package completeness, absence of placeholders/TODO markers, accessibility and E2E evidence, documentation/Completion Report completeness, architectural fidelity, and ADR honour — without creating a new foundational standard.

## Compatibility

v1.1.0 is backward compatible with v1.0.0 review outcomes vocabulary. Existing Accepted programmes are not reopened. Future ENG Owner Acceptances SHALL apply ECR.

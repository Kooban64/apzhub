# Responsive behaviour

| Field  | Value      |
| ------ | ---------- |
| Status | **LOCKED** |

Platform Admin is **primarily desktop software**. Do not compromise the desktop experience to force every administrative function onto a phone.

## Mobile / narrow — support

```text
Platform status
Incident inspection
Tenant lookup
Provisioning inspection
Approvals
Critical actions
```

## Desktop / tablet oriented — may degrade gracefully

```text
RBAC configuration
Provider configuration
Commercial configuration
Audit analysis
```

On small viewports: collapse sidebar to icon rail or drawer; preserve header search and critical attention paths.

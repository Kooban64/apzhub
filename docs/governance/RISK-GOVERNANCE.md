## Risk domains

| Domain      | Examples                                          |
| ----------- | ------------------------------------------------- |
| Strategic   | Premature FIN-001; over-claiming 1.1 capabilities |
| Operational | Host coexistence; backup drills; alert gaps       |
| Security    | Secrets; AuthZ; superadmin misuse                 |
| Compliance  | Retention; access reviews; marketing honesty      |
| Delivery    | Unauthorised scope; freeze violations             |
| Vendor      | Engine EOL; license drift; EE dependency creep    |

## Risk Committee duties

1. Maintain consolidated risk view
2. Set treatment owners and due dates
3. Block marketing that contradicts Known Limitations
4. Escalate STOP-pressure attempts to Owner

## Appetite (default)

Prefer **honest PRWL** over silent risk acceptance that looks like “Production Ready” without limitations.

# Administration Capability Catalogue UI Guide

**Milestone:** APZADMIN-004

## Surface

Sidebar **Capabilities** — list + detail of capability metadata.

## Displayed flags

Enabled, Available, Healthy (metadata), Certified, Production Ready, Limitations, Owner, Version, Documentation reference.

## Boundaries

- Catalogue only — does not enable/disable runtime engines
- Healthy flag is registered metadata, not a live probe
- Diagnostics section repeats unavailable runtime/AI/Event Bus cards

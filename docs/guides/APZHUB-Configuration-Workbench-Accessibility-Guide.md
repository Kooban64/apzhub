# Configuration Workbench Accessibility Guide

- Page heading hierarchy (eyebrow + h1 + section h2)
- Toolbar labelled `Configuration commands`
- Tables include captions (sr-only) and keyboard row selection (Enter/Space)
- Loading and error announcements via `role="status"` / `role="alert"`
- Status cards include text labels (not colour-only)
- Focusable controls use shared `@apzhub/ui` Button/Input components
- Responsive: grids collapse on narrow widths; tables scroll horizontally

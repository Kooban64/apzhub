# Identity Membership Guide

`IdentityMembership` links a user to a target:

| Kind | Target |
| --- | --- |
| `group` | Group id |
| `organisation` | Organisation id |
| `tenant` | Tenant id |
| `department` | Department id |

Helpers in `@apzhub/identity-core`: `validateIdentityMembership`, `summarizeMembership`, `isActiveMembership`.

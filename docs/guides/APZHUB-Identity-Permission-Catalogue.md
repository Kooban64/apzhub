# Identity Permission Catalogue

| Permission | Intent |
| --- | --- |
| `identity.*` | Wildcard |
| `identity.read` | Read identity metadata |
| `identity.manage` | Manage identity metadata |
| `identity.user` | User metadata operations |
| `identity.group` | Group metadata operations |
| `identity.role` | Role metadata operations |
| `identity.organization` | Organisation metadata operations |
| `identity.tenant` | Tenant metadata operations |
| `identity.assignment` | Permission / service assignment metadata |
| `identity.audit` | Audit trail access |

# APZHUB Metrics Capability Limitations Guide

**Milestone:** APZMETRICS-004

The Workbench always surfaces capability limitation banners for unavailable features:

- Metric calculation
- Formula execution
- KPI execution
- Analytics / reporting / dashboards
- Provider integrations (Prometheus, Grafana, OpenTelemetry)
- Event Bus / AI

Disabled service → `METRICS_SERVICE_UNAVAILABLE` (503) with dedicated unavailable UI.

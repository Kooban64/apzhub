# APZHUB Metrics Metadata Guide

**Milestone:** APZMETRICS-002

Platform Metrics Services manage **metadata only**:

- Metric definitions, versions, taxonomy
- Dimensions, labels, units
- Formula / aggregation / threshold **metadata** (never evaluated)
- Ownership, consumers, relationships, dependencies
- Retention and classification catalogues
- KPI definitions and targets (never executed)

Diagnostics report platform readiness, persistence mode, and registration state — not provider health.

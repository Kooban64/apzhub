# Notification Workbench Views Guide (APZNOTIFY-004)

- **Overview** — counts, health/readiness, prominent **DELIVERY PROVIDERS NOT AVAILABLE**
- **Notifications** — list + detail + recipients/references summary; lifecycle commands
- **Templates / Preferences / Categories** — list + detail metadata
- **Channels** — metadata with delivery unavailable
- **Recipients / References** — scoped to selected notification; no address edit / product deep-links
- **Audit** — read-only timeline
- **Diagnostics** — health, readiness, capabilities; providers/workers/Event Bus/realtime unavailable

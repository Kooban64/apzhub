# Workflow Workbench — Commands Guide

**Milestone:** APZWORKFLOW-004

| Command | Behaviour |
|---------|-----------|
| Refresh | Invalidate TanStack Query caches |
| Copy ID | Clipboard selected workflow id |
| Validate | `validateWorkflow` via client |
| Publish / Archive / Restore / Transition | Lifecycle facades (server authz) |
| Export JSON / YAML / Markdown | Download canonical metadata only |

No execute, schedule, activate, or n8n commands.

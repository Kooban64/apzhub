## Entry criteria (reminder)

A product may enter a **new** implementation programme only when:

1. Product Definition Pack complete
2. Architecture approved
3. Dependencies available
4. Marked **Implementation Ready** (or Owner explicitly re-opens scope)
5. **Owner Approval** of a named programme

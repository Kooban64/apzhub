# Operational — APZ-ANALYTICS-CAPABILITY-001

## Capabilities delivered

| Capability                   | Surface                                                                            |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| Executive Question Catalogue | `/workspace/analytics/questions` · role-filtered catalogue with evidence + actions |
| Decision Packs               | `/workspace/analytics/decision-packs` · rule-based packs (no AI)                   |
| Trend Analysis               | `/workspace/analytics/trends` · delivery / support / workflow / quality            |
| KPI Management               | `/workspace/analytics/kpis` · define, own, target, track history                   |
| Decision Timeline            | `/workspace/analytics/timeline` · decisions with evidence refs                     |
| Native experience            | Question-first navigation, Help, Settings, breadcrumbs retained                    |

## SoR posture

- Analytics stores **insight metadata only** (packs, derived trend snapshots, KPI definitions, decision history records).
- Operational truth remains in Projects, Support, Workflow, Time, and other SoRs.
- Recommended actions are rule-based from the question catalogue — never AI-generated.

## Audience roles

Executive · Manager · Project Manager · Support Manager · Team Member

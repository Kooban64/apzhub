## Checklist (every APZ Analytics change)

| #   | Question                                                              | Required evidence                           |
| --- | --------------------------------------------------------------------- | ------------------------------------------- |
| 1   | Was a Quality Flow opened?                                            | Flow / QI identifier                        |
| 2   | Was Impact evaluated?                                                 | Impact record                               |
| 3   | Were policies applied?                                                | Policy selection / result                   |
| 4   | Was a Decision Package produced?                                      | Decision package artefact                   |
| 5   | Was evidence captured?                                                | `evidence/` folder or release pack          |
| 6   | Was operational learning recorded when something hurt or taught?      | Friction Log and/or Learning Register entry |
| 7   | Was Decision Companion identity preserved (no dashboard-first drift)? | UX / docs review notes                      |
| 8   | Did administrative reporting remain secondary and role-gated?         | Permission / nav review                     |

**Pass condition:** all applicable questions answered **yes** for the change.

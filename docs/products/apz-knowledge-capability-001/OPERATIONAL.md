# Operational — APZ-KNOWLEDGE-CAPABILITY-001

## Capabilities delivered

| Capability                 | Surface                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------------- |
| Knowledge Object Lifecycle | Draft → Review → Approved → Archived · version history · ownership                              |
| Operational Lessons        | `/workspace/knowledge/lessons` · structured lesson objects                                      |
| Best Practice Library      | `/workspace/knowledge/library` · standards / procedures / practices / guides / reference        |
| Decision Knowledge         | `/workspace/knowledge/decision-knowledge` · references decisions; does not own them             |
| Knowledge Quality          | `/workspace/knowledge/quality` · rule-based ownership, review, expiry, duplicates, stale        |
| Native experience          | Question-led navigation · Organisational Memory identity · Help · Settings · breadcrumbs · a11y |

## SoR posture

- Knowledge stores **organisational memory metadata only**.
- Operational truth remains in Projects, Workflow, Analytics decisions, Documents, and other SoRs.
- Decision knowledge stores a **reference** (`decisionRef`) — never the decision record itself.
- Quality validation is **rule-based only** — no AI.

## Explicitly out of scope (deferred)

AI-generated knowledge · RAG · Enterprise Search redesign · automatic document ingestion · chat assistants · context overlays · knowledge recommendations

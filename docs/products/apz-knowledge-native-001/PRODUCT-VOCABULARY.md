## Rule

User-facing **APZ Knowledge** identity uses **organisational memory** language.

Product identity: **Enterprise Organisational Memory** — curated understanding that helps people act correctly in context.

## Authoritative terms

| Term                      | Means                                                       | Does not mean                   |
| ------------------------- | ----------------------------------------------------------- | ------------------------------- |
| **APZ Knowledge**         | Enterprise Organisational Memory (the product)              | Discovery, search, learning, AI |
| **Knowledge** (short)     | Same as APZ Knowledge when naming the product               | Platform discovery plumbing     |
| **Organisational memory** | Curated lessons, standards, procedures, rationale, guidance | Files, tickets, policies        |
| **Memory Companion**      | Knowledge appearing beside work                             | Standalone wiki destination     |
| **Knowledge Discovery**   | Finding organisational memory                               | The product itself              |
| **Knowledge Overlay**     | Contextual presentation inside another product              | Product home                    |
| **Learning**              | APZQEP skills / practice improvement                        | APZ Knowledge                   |
| **Search**                | Retrieval capability                                        | Product identity                |
| **AI Assistant**          | Consumer of memory                                          | Reason Knowledge exists         |

## Forbidden identity frames

| Frame                                   | Why forbidden                                         |
| --------------------------------------- | ----------------------------------------------------- |
| Document library / wiki                 | Documents owns files; memory is curated understanding |
| Search portal                           | Search is a consumer capability                       |
| AI chat                                 | AI consumes memory; never defines Knowledge           |
| QEP Learning                            | Separate capability under APZQEP                      |
| “Knowledge” as ops health for discovery | Label must say **Knowledge discovery**                |

# Operational — APZ-WORKFLOW-CAPABILITY-001

## Capabilities delivered

| Capability                     | Surface                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| Business Journey Designer      | `/workspace/workflow/journeys` · stages, transitions, outcomes, entry/exit conditions |
| Workflow Template Library      | `/workspace/workflow/templates` · 8 seeded editable templates                         |
| Process Ownership              | Owner, steward, version, publication status, review cycle                             |
| Operational Process Monitoring | `/workspace/workflow/monitoring` · active / stalled / overdue / completion            |
| Process Governance             | draft → review → approved → retired with audit history                                |
| Native experience              | Help, Settings, breadcrumbs, My Work / Context compatibility retained                 |

## Intent principle

- Workflow remains authoritative for business intent.
- Automation execution, scripting, rules engines, and schedulers remain out of scope.
- Product vocabulary uses Process / Stage / Transition / Participant / Outcome only.

Project Approval · Change Request · Incident Resolution · Employee Onboarding · Procurement · Leave Approval · Contract Review · Quality Review

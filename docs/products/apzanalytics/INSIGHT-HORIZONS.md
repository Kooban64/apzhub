## Purpose

Organise enterprise questions and answer paths by decision horizon — not by chart type.

## Horizons

### Operational — “What is happening today?”

| Examples        | Related questions (see ENTERPRISE-QUESTIONS) |
| --------------- | -------------------------------------------- |
| Open work       | EQ-E01, EQ-E02                               |
| SLA status      | EQ-M03                                       |
| Active projects | EQ-E01, EQ-P01                               |
| Capacity        | EQ-E03                                       |

### Tactical — “What changed?”

| Examples                             | Related questions |
| ------------------------------------ | ----------------- |
| Delivery trend                       | EQ-M01            |
| Incident trend                       | EQ-S01, EQ-M03    |
| Throughput / lead time / bottlenecks | EQ-M02, EQ-W01    |

### Strategic — “What should we do?”

| Examples             | Supports                         |
| -------------------- | -------------------------------- |
| Portfolio investment | Product Board / quarterly review |
| Process improvement  | Workflow + delivery decisions    |
| Resource planning    | Overload / effort insight        |
| Operational risk     | At-risk projects / blockage      |
| Capability maturity  | Quality / release safety trends  |

## Rule

Every Analytics investment maps to at least one horizon and at least one business question. “Add a dashboard” without a horizon and question fails the Decision Before Measurement principle.

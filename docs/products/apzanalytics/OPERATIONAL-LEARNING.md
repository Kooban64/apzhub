## Analytics-specific learning themes

- Did users start from business questions or from dashboard / report catalogues?
- Did dashboard-first vocabulary re-enter the standard UX?
- Did administrative reporting remain secondary?
- Was deferred AI / predictive capability mis-classified as an Analytics defect?
- Did Analytics stay above Systems of Record (consume, never own)?

## Anti-patterns

- Skipping learning because “it was only docs”
- Opening Lane 1 or AI programmes from a single friction note
- Treating missing advanced insight features as Native Adoption failure
- Collapsing Analytics into a reporting console “for power users”

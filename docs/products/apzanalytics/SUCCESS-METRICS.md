Metrics measure whether **questions get answered** and **decisions improve** — not widget count.

| Metric                        | Intent                                                   |
| ----------------------------- | -------------------------------------------------------- |
| Question coverage             | Share of ENTERPRISE-QUESTIONS with a trusted answer path |
| Decision use                  | Qualitative: insight used in a named decision            |
| Time-to-insight               | Time from question to usable answer in APZHUB            |
| SoR leakage incidents         | Count of Analytics treated as operational truth          |
| Parallel-reporting decline    | Decline in ad-hoc exports for covered questions          |
| Cross-product insight use     | Answers that combine ≥2 RI observations                  |
| Vocabulary / identity defects | BI-engine branding or “dashboard product” framing        |

Baseline and targets are set after Owner Approval and first Native Adoption evidence — not in this mission pack.

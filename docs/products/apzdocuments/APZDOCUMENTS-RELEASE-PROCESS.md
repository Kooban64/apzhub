## Rule

APZ Documents ships only through APZQEP-labelled releases after Quality Flow, Decision Package, and Evidence are complete.

## Path

```text
Authorised change → Quality Flow → Checklists → Decision Package →
Evidence → Release label → Ship → Operational Learning → Close
```

## Non-negotiables

1. No silent hotfixes outside APZQEP
2. No engine/provider names in release notes
3. No consumer-product wiring without separate Owner Auth
4. Known Limitations remain honest

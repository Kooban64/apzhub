## Rule

Every completed APZ Documents release records Operational Learning.  
Friction is classified: Engineering · Operational · User · Training · Documentation · Product Enhancement · Portfolio Capability.

## Documents-specific learning themes

- Did users start from work or from the library?
- Did provider/engine identity leak?
- Were SoR boundaries respected in consumer requests?
- Was deferred consumer wiring mis-classified as a Documents defect?

## Anti-patterns

- Skipping learning because “it was only docs”
- Opening Lane 1 programmes from a single friction note
- Treating incomplete consumer wiring as Native Adoption failure

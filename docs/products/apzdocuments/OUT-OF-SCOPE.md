APZ Documents will **not** become these products. Strong boundaries protect focus and portfolio clarity.

| Not APZ Documents                           | Belongs to                                                         |
| ------------------------------------------- | ------------------------------------------------------------------ |
| Generic file-store / “Paperless UI” brand   | Out of product identity — engine may exist but must stay invisible |

| Time tracking and utilisation               | APZ Time                                                           |
| Project / delivery coordination             | APZ Projects                                                       |
| Project / ticket / quality **metadata SoR** | Owning products (see [SYSTEM-OF-RECORD.md](./SYSTEM-OF-RECORD.md)) |
| Workflow / automation product               | APZ Workflow                                                       |
| Analytics / BI product                      | APZ Analytics                                                      |
| Legal practice product                      | APZ Law Platform                                                   |
| Quality engineering platform                | APZQEP                                                             |

| Unified notifications product               | Platform Notifications (Lane 1)                                    |
| Identity provider / authentication product  | APZHUB platform identity                                           |
| General-purpose collaboration suite         | Outside this mission                                               |

## Boundary rules

1. Adjacent products integrate at the **APZHUB product** level when authorised — APZ Documents does not absorb them.
2. “Helpful while we’re here” expansions that cross these boundaries require separate Owner Authorisation.
3. Out-of-scope does not mean “never useful later”; it means “not this product’s job.”
4. Platform evolution (My Work, Search, Notifications, AI) remains **Lane 1** — not justified by opening Documents.
5. Users must never be trained to “upload to [engine name].”

## Core KPIs

| Metric                            | Definition (business)                                                                     | Linked outcomes |
| --------------------------------- | ----------------------------------------------------------------------------------------- | --------------- |
| Document findability              | Share of sought documents located in APZ Documents without external chase                 | BO-01, BO-04    |
| Ownership coverage                | Share of active documents with a named owner                                              | BO-02           |
| Access appropriateness            | Qualitative / audit signal that sensitive documents are permissioned as intended          | BO-03           |
| Version clarity                   | Share of referenced documents where “current version” is unambiguous                      | BO-05           |
| Cross-tool document chase load    | Survey / observation signal of time spent reconstructing documents outside APZ Documents  | BO-01, BO-08    |
| Related-product attachment        | Where authorised: share of relevant Project / Support / quality items linked to documents | BO-06, BO-09    |
| Retention / governance adherence  | Share of governed document classes following agreed retention / ownership practice        | BO-07           |
| Time-to-retrieve                  | Elapsed time to retrieve a known document for an operational task (sample)                | BO-04, BO-08    |
| Duplicate / shadow-copy incidence | Observed reliance on email/chat/drive copies when an APZHUB document should exist         | BO-05, BO-01    |
| Leadership trust signal           | Qualitative: leaders trust APZ Documents as the place for critical records                | BO-01, BO-07    |

## Metric rules

1. Targets and baselines are set after mission approval using real operational data — not invented in this programme.
2. Metrics serve outcomes; they do not justify unrelated feature work.
3. No dashboard design in APZ-DOCUMENTS-000.

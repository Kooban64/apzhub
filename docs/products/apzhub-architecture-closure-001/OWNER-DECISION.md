## Decision

The architectural foundation of APZHUB is declared **complete**.

Future architectural work shall occur only when **implementation evidence** demonstrates that an existing constitutional principle or capability contract is insufficient.

Architecture is no longer a workstream.  
It is a **governed asset**.

## Permanent rule

> **No architectural artefact shall be created solely because one might be useful. Every new architectural artefact must be justified by implementation evidence.**

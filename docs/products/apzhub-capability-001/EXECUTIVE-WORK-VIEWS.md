## Purpose

Different roles consume the same work model differently. Views are **lenses**, not separate work systems.

## Role lenses

### Executive

| Focus                 | Typical queues / views                          |
| --------------------- | ----------------------------------------------- |
| Outcomes and risk     | High priority, Blocked, Ready to release        |
| Cross-capability load | Waiting for others (organisational bottlenecks) |
| Decision throughput   | Needs approval (escalations)                    |

Executives rarely need every assigned action; they need **signals that threaten outcomes**.

### Manager

| Focus            | Typical queues / views                  |
| ---------------- | --------------------------------------- |
| Team obligations | Assigned to me + team variants (future) |
| Due commitments  | Due today, High priority                |
| Unblocking       | Blocked, Waiting for others             |
| Approvals        | Needs approval                          |

Managers balance personal work with team flow.

### Engineer / Builder

| Focus            | Typical queues / views            |
| ---------------- | --------------------------------- |
| Personal actions | Assigned to me, Due today         |
| Quality gates    | Ready to release, Quality actions |
| Dependencies     | Blocked, Waiting for others       |

Deep work still happens in product workspaces; My Work answers “what next?”

### Support / Service

| Focus               | Typical queues / views                    |
| ------------------- | ----------------------------------------- |
| Service obligations | Assigned to me, Waiting for me, Due today |
| Escalations         | High priority, Needs approval             |
| Continuity          | Recently completed                        |

### QA / Quality

| Focus              | Typical queues / views                            |
| ------------------ | ------------------------------------------------- |
| Evidence and gates | Quality actions, Ready to release, Needs approval |
| Risk               | Blocked, High priority                            |

### Operations

| Focus                    | Typical queues / views                     |
| ------------------------ | ------------------------------------------ |
| Continuity and incidents | Needs my attention, High priority, Blocked |
| Release readiness        | Ready to release                           |

## Shared rules across roles

1. Same work definition for everyone.
2. Role changes **default lenses**, not the meaning of work.
3. No role gets a private quality or identity model.
4. Permissions still bound every view.

## Non-goals

- Building dashboards or analytics in this programme
- Role-based product silos
- Separate “executive portal” outside APZHUB

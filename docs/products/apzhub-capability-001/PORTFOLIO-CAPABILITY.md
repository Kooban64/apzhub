## Capability statement

> **Unified Work Experience** is an APZHUB Horizon 3 capability: one work model spanning the portfolio so people act on organisational obligations without choosing an application first.

Products remain owners of their domains. They **contribute** work items and context; they do not own My Work.

## Contribution model

| Product                                                 | Contributes work kinds (examples)                             | Remains owner of                         |
| ------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------- |
| **APZ Projects**                                        | Actions, coordination, deliverables, reviews                  | Delivery planning and execution surfaces |
| **APZ Support**                                         | Requests, actions, approvals (service)                        | Service conversation and resolution      |
| **APZ Time**                                            | Records (effort), related actions                             | Time capture and accountability          |
| **APZQEP**                                              | Quality actions, approvals, ready-to-release gates            | Quality Flows, evidence, release process |
| **Future products** (Documents, Workflow, Analytics, …) | Reviews, decisions, automated actions, insight-driven actions | Their native product experiences         |

## Ownership boundaries

| Concern                       | Owner                                               |
| ----------------------------- | --------------------------------------------------- |
| Work definition & My Work     | **APZHUB** (this capability)                        |
| Product domain UX             | Each native product                                 |
| Identity / permissions        | APZHUB                                              |
| Quality of engineering change | APZQEP                                              |
| Implementation engines        | Invisible; never contribute user-facing work labels |

## Compatibility

This capability must remain compatible with:

- Enterprise Operating Model
- Enterprise Capability Model
- Native Adoption Standard
- APZQEP Enterprise Quality Baseline
- Platform Experience Principles (one identity, workspace, search, attention, audit)

## Future engineering posture (not authorised here)

When Owner authorises implementation:

1. Aggregate into My Work **without changing product ownership**
2. Map product statuses into the shared lifecycle
3. Preserve permission filtering
4. Keep engines invisible
5. Run changes through APZQEP

No product is demoted to a feed. Each remains a first-class native APZHUB product.

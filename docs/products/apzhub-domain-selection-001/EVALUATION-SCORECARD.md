## Score guidance (1–5)

| Score | Meaning                                         |
| ----- | ----------------------------------------------- |
| 1     | Weak / high risk / low value / disproportionate |
| 2     | Limited                                         |
| 3     | Moderate / acceptable                           |
| 4     | Strong                                          |
| 5     | Compelling / clear enterprise leverage          |

Delivery Complexity: **5** = proportionate and feasible; **1** = disproportionate effort or premature.

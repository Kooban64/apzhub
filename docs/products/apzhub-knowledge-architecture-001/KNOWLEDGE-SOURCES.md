## Rule

Sources **feed** organisational memory.  
Sources are **not** owned by Knowledge.

```text
Source (SoR / event / learning)
        →
Signal for curation
        →
Approved memory object (Knowledge domain)
```

---

## Source catalogue

| Source                                           | What it contributes                                          | What Knowledge must not take                                                    |
| ------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| **APZ Documents**                                | Files and artefacts that may be **explained** or **linked**  | File SoR, versions, storage                                                     |
| **APZ Law**                                      | Policies / obligations that need **explanation in practice** | Governance SoR, legal advice                                                    |
| **APZ Projects**                                 | Delivery lessons, delivery patterns                          | Project / work-item truth                                                       |
| **APZ Support**                                  | Recurring incident patterns, runbook candidates              | Ticket SoR                                                                      |
| **APZ Time**                                     | Effort-classification guidance signals                       | Time entry SoR                                                                  |
| **APZ Workflow**                                 | Why a process stage exists; procedural intent clarification  | Process definition SoR                                                          |
| **APZ Analytics**                                | Decision questions / outcomes worth remembering as rationale | Insights as SoR (Analytics owns none; still not Knowledge’s job to own metrics) |
| **APZQEP**                                       | Operational learning, friction, quality practices            | Quality Flow / Decision Package / evidence SoR                                  |
| **Operational Learning Register / Friction Log** | Portfolio learning candidates                                | Becoming a second learning register                                             |
| **Product Board / Owner decisions**              | Strategic rationale worth institutionalising                 | Replacing Board minutes as SoR                                                  |
| **People (humans)**                              | Expert capture, interviews, authored guidance                | Unreviewed tribal dump as published memory                                      |

---

## Source classes

| Class                     | Description                                                          |
| ------------------------- | -------------------------------------------------------------------- |
| **Authoritative records** | SoR objects elsewhere — Knowledge may only **reference**             |
| **Experience signals**    | Lessons, friction, retrospectives — must be curated before publish   |
| **Explanatory drafts**    | Human-authored understanding of “how / why”                          |
| **Derived candidates**    | Patterns suggested by recurrence — still require curation + approval |

---

## Promotion rule

Nothing becomes organisational memory by automatic import alone.

| Allowed                                                  | Forbidden                                         |
| -------------------------------------------------------- | ------------------------------------------------- |
| Curator creates memory that **points to** a Document     | Bulk-copying the Documents library into Knowledge |
| Curator explains a Law policy in operational language    | Duplicating the policy catalogue as Knowledge SoR |
| Curator captures a Project lesson with project reference | Mirroring project tasks into Knowledge            |
| Curator turns APZQEP learning into guidance              | Replacing APZQEP evidence packs                   |

---

## AI note (boundary only)

AI may later **propose** candidate memory from sources.  
AI does not **approve** memory.  
AI programmes remain out of scope for this architecture pack.

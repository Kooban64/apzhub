## Separation guide

| Kind                      | Definition                                                           | Goes to                                                   |
| ------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------- |
| **Confirmed defect**      | Incorrect behaviour vs intended / documented behaviour; reproducible | This register → Owner Auth for fix under APZQEP           |
| **Usability observation** | Works but confused or slow                                           | Friction Register (Product / Portfolio / Training / Docs) |
| **Enhancement request**   | Preference or new capability                                         | Friction Register — **not** backlog until Board invests   |
| **Training issue**        | Intended path unknown to user                                        | Training / Documentation                                  |
| **Process issue**         | Org workflow, not software                                           | Operational Process                                       |

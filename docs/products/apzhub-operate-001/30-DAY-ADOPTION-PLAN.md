# 30-Day Adoption Plan

| Field     | Value              |
| --------- | ------------------ |
| Programme | APZHUB-OPERATE-001 |
| Status    | **IN FORCE**       |

Controlled internal rollout. Expand cohort only when the prior week is stable.

## Week 1 — Pilot foundation

| Day focus | Actions                                                       |
| --------- | ------------------------------------------------------------- |
| Prep      | Complete [GO-LIVE-CHECKLIST.md](./GO-LIVE-CHECKLIST.md)       |
| Cohort    | 1–2 teams spanning at least two of Projects / Support / Time  |
| Enable    | Roles + products ([ROLE-ENABLEMENT.md](./ROLE-ENABLEMENT.md)) |
| Train     | Day-0 onboarding for every pilot user                         |
| Observe   | Daily: can they start in My Work?                             |

**Exit Week 1:** Pilot users signed in; My Work reachable; support contact known.

## Week 2 — Real work

| Focus    | Actions                                       |
| -------- | --------------------------------------------- |
| Work     | Pilot does real tasks only in APZHUB products |
| Time     | Effort captured in APZ Time where expected    |
| Support  | Issues filed via Support Model                |
| Learning | Capture friction (do not build)               |

**Exit Week 2:** At least one full work week of real usage; friction list started.

## Week 3 — Expand carefully

| Focus          | Actions                                                                 |
| -------------- | ----------------------------------------------------------------------- |
| Expand         | Add one adjacent cohort **or** deepen product use—not both aggressively |
| My Work Review | Hold first [My Work Review](../framework/APZHUB-MY-WORK-REVIEW.md)      |
| Metrics        | Baseline DAU / My Work / friction counts                                |

**Exit Week 3:** First My Work Review answers written; no unauthorised engineering opened.

## Week 4 — Stabilize

| Focus     | Actions                                          |
| --------- | ------------------------------------------------ |
| Stabilize | Fix only true defects under APZQEP if authorised |
| Comms     | Share “start in My Work” reminder                |
| Plan      | Confirm 90-day learning cadence                  |
| Gate      | Owner decides whether to widen further           |

**Exit Week 4:** Recommendation for continued internal use; evidence pack for Portfolio Review.

## Explicit non-goals (30 days)

- No Documents / Workflow / Analytics adoption
- No Notifications / Search / Executive Workspace programmes
- No “while we’re here” features

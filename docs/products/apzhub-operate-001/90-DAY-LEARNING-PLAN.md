# 90-Day Learning Plan

| Field     | Value              |
| --------- | ------------------ |
| Programme | APZHUB-OPERATE-001 |
| Status    | **IN FORCE**       |

## Purpose

Collect operational evidence so Portfolio Review can invest deliberately—or do nothing.

## Cadence

| When                             | Activity                                                              | Output          |
| -------------------------------- | --------------------------------------------------------------------- | --------------- |
| Weekly (light)                   | Support friction triage                                               | Themes list     |
| After each meaningful use period | [My Work Review](../framework/APZHUB-MY-WORK-REVIEW.md)               | Five answers    |
| Monthly                          | Metrics snapshot ([OPERATIONAL-METRICS.md](./OPERATIONAL-METRICS.md)) | Trend note      |
| End of 90 days                   | Portfolio Learning Pack                                               | Decision inputs |

## What to capture

| Domain        | Questions                                                                      |
| ------------- | ------------------------------------------------------------------------------ |
| My Work       | What never appeared? What was ignored? What caused healthy vs unhealthy leave? |
| Projects      | Delivery friction after handoff from My Work                                   |
| Support       | Access / how-to / defect mix                                                   |
| Time          | Capture compliance; timesheet friction                                         |
| Cross-product | Unnecessary navigation; missing context links                                  |

## Decision filter (end of 90 days)

For each theme:

1. No action
2. Product enhancement (owning product)
3. Portfolio capability
4. Platform evolution (exceptional)

Apply: measurable friction + evidence + Portfolio Review priority.  
Remember: **the platform earns the right to evolve.**

## Registers

| Register                     | Location                                                  |
| ---------------------------- | --------------------------------------------------------- |
| My Work Review notes         | Product Board / ops folder (org choice)                   |
| Product operational learning | Product ops packs (e.g. apzprojects OPERATIONAL-LEARNING) |
| Portfolio patterns           | Emerging Portfolio Patterns (observe only)                |

## Explicit non-goals

Do not invent a new analytics platform for learning.  
Do not open programmes mid-flight without Owner Auth.

## Measurable outcomes

| Outcome                           | Description                                                              | Directional indicator                                               |
| --------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Faster onboarding                 | New joiners reach correct practice sooner via approved memory in context | Time-to-competent on recurring tasks falls                          |
| Reduced repeated mistakes         | Lessons from Projects / Support become published memory                  | Repeat-incident / repeat-defect themes decline where memory applies |
| Better operational consistency    | Procedures and standards used at point of work                           | Variance in how teams perform the same work decreases               |
| Improved decision quality         | Decision rationale and guidance available when deciding                  | Fewer decisions remade without prior organisational context         |
| Increased organisational learning | Experience is captured, curated, and reused                              | Published lessons with source derivation rise                       |
| Reduced knowledge loss            | Understanding survives people and project closure                        | Critical memory retained after role/project exit                    |

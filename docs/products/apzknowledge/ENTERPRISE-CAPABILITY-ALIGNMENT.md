## Alignment rule

APZ Knowledge **complements** every enterprise product. It **replaces none**.

| Product       | Owns                                  | Knowledge complements by                                                 |
| ------------- | ------------------------------------- | ------------------------------------------------------------------------ |
| **Projects**  | Work                                  | Surfacing lessons, delivery playbooks, and standards beside project work |
| **Support**   | Incidents                             | Surfacing runbooks and “solved before” memory beside tickets             |
| **Time**      | Effort                                | Surfacing guidance on how effort and charging are understood             |
| **Documents** | Information                           | Explaining and linking files — never owning file lifecycle               |
| **Workflow**  | Business intent                       | Explaining why processes exist and how to follow them                    |
| **Analytics** | Insight                               | Remembering decision rationale; Analytics still owns insight             |
| **Law**       | Governance                            | Explaining governance in practice — Law owns policies and evidence       |
| **APZQEP**    | Quality evidence / practice authority | Remembering standards and approved practice — APZQEP owns packs          |

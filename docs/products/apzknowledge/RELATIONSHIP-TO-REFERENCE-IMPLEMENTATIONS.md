## Derivation model

APZ Knowledge **derives** organisational memory from trusted enterprise experience across the Enterprise Productivity Core and Enterprise Governance Layer. It does **not** redefine RI #001–#007.

```text
Trusted experience (RI / APZQEP / Board)
        →
Curate · explain · contextualise (Knowledge)
        →
Deliver memory in context (consumers = same RIs)
```

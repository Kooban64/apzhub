## What was hard

1. **Semantic collision** — “Knowledge” already meant discovery, QEP learning, and product ambition.
2. **Abstract identity** — organisational memory is easier to dilute into wiki/search/AI than operational products.
3. **Domain-first path** — Definition → Architecture → Mission before Native Adoption was necessary and worth preserving.

## What worked

1. Organisational Memory Audit as product-specific identity test (not Playbook change).
2. Vocabulary Integrity as portfolio law.
3. Memory Companion experience model without premature consumer wiring.
4. Unchanged Playbook N-01…N-04.

## Carry forward

- One defining identity question per product.
- One authoritative meaning per business concept.
- Judge future domains: new enterprise capability vs duplicate.

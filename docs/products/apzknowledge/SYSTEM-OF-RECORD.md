## Immutable SoR principles

> Knowledge never becomes a System of Record for operational truth.  
> Knowledge references trusted Systems of Record. It does not replace them.

## APZ Knowledge owns (authoritative — memory only)

| Datum                            | Notes                                     |
| -------------------------------- | ----------------------------------------- |
| Organisational memory objects    | Curated understanding entities            |
| Memory taxonomy / collections    | Organisation of memory                    |
| Applicability / context metadata | Where memory applies                      |
| Memory lifecycle state           | Draft / published / retired / superseded  |
| Approval records for memory      | Who approved organisational understanding |

## APZ Knowledge does not own

| Datum                                        | System of Record                                   |
| -------------------------------------------- | -------------------------------------------------- |
| Files                                        | Documents                                          |
| Policies / obligations / governance evidence | Law                                                |
| Delivery / tickets / time                    | Projects / Support / Time                          |
| Process definitions                          | Workflow                                           |
| Insight / decision SoR                       | Analytics                                          |
| Quality evidence packs                       | APZQEP                                             |
| Board minutes as legal / formal record       | Board / platform records (Knowledge may reference) |

## Derivation rule

Memory is **derived from** trusted experience and **references** SoRs.  
It does not duplicate or replace them.

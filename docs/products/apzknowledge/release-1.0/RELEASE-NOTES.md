## What is delivered

Permissioned users can enter APZ Knowledge as Memory Companion, browse and curate organisational memory (lessons, library, decision knowledge, quality) on a durable fail-closed Postgres path, with honest limitation disclosure and Delivery-Standard hardening.

## Honest limitations (v1.0)

- Consumer overlays in other products are **deferred / not shipped**.
- AI / RAG / chat are **out of product identity**.
- Production requires a durable organisational memory store — unavailable storage **fails closed** (no silent in-memory degrade).
- Diagnostics are **operator surfaces**, not the default companion path.

## Out of scope

Knowledge 2.0, AI/RAG productisation, redesign, native programme reopen, architecture change without ADR.

# APZ Knowledge — User Guide (v1.0)

1. Open **APZ Knowledge** Home (`/workspace/knowledge`).
2. Browse **Memory types**, **Operational lessons**, **Best practice library**, or **Decision knowledge**.
3. Open a memory object for detail and lifecycle (when permitted).
4. Use **Help** for product identity and current limitations.
5. Use **Memory Companion** to understand how memory accompanies other products.

Consumer overlays in other products are not shipped in v1.0. AI / RAG chat is not part of this product.

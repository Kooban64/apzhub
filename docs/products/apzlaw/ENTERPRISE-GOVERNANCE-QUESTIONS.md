## Rule

> Governance questions come before contract vaults, case lists, or legal databases.

These questions define the product. Implementation tooling does not.

## Catalogue

| ID    | Question                                    |
| ----- | ------------------------------------------- |
| GQ-01 | Are we allowed to do this?                  |
| GQ-02 | What obligations apply?                     |
| GQ-03 | Which policies govern this action?          |
| GQ-04 | What evidence must be retained?             |
| GQ-05 | Which regulatory requirements are relevant? |

## Extension rule

New APZ Law scope must introduce or refine a **governance question** that advances an obligation, policy, compliance, or evidence outcome. “Add a contract module” is not a valid scope driver by itself.

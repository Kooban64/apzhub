## APZ Law owns (authoritative)

| Datum                                        | Notes                                             |
| -------------------------------------------- | ------------------------------------------------- |
| Policies (governance catalogue)              | Which policies exist and apply                    |
| Obligations                                  | What the organisation must do / not do            |
| Compliance artefacts (as governance objects) | Distinct from general Documents library           |
| Legal artefacts under governance             | Contracts, filings, etc. as governed artefacts    |
| Governance evidence retention requirements   | What must be retained and why                     |
| Review / attestation records for governance  | Coordination state — not counsel’s advice content |

## APZ Law does not own

| Datum                         | System of Record      |
| ----------------------------- | --------------------- |
| General work documents        | APZ Documents         |
| Project / ticket / time truth | RI #001–#003          |
| Business process definitions  | APZ Workflow          |
| Performance insight           | APZ Analytics         |
| Quality / release evidence    | APZQEP                |
| Legal advice content          | Counsel (outside SoR) |

## Rule

Law may **reference** Documents and operational products. It never becomes their SoR. Counsel advice is never treated as product-generated truth.

APZ Law’s SoR covers **APZHUB organisational governance** only. It is not a System of Record for external legal practice, matters, trust accounts, or law-firm operations.

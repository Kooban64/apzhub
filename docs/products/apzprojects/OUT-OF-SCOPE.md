# APZ Projects — Out of Scope

| Field     | Value            |
| --------- | ---------------- |
| Programme | APZ-PROJECTS-000 |
| Status    | **APPROVED**     |

APZ Projects will **not** become these products. Strong boundaries protect focus and portfolio clarity.

| Not APZ Projects                           | Belongs to                                                             |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| Helpdesk / service request management      | APZ Support                                                            |
| Time tracking and utilisation              | APZ Time                                                               |
| Document / records management              | APZ Documents                                                          |
| Workflow / automation product              | APZ Workflow                                                           |
| Analytics / BI product                     | APZ Analytics                                                          |
| Legal practice product                     | APZ Law Platform                                                       |
| Quality engineering platform               | APZQEP (infrastructure — not absorbed into Projects)                   |
| CRM / sales pipeline                       | Outside this mission (unless separately authorised as another product) |
| Finance / billing product                  | Outside this mission                                                   |
| Identity provider / authentication product | APZHUB platform identity (not owned by APZ Projects)                   |
| General-purpose collaboration suite        | Outside this mission                                                   |

## Boundary rules

1. Adjacent products integrate at the **APZHUB product** level when authorised — APZ Projects does not absorb them.
2. “Helpful while we’re here” expansions that cross these boundaries require separate Owner Authorisation.
3. Out-of-scope does not mean “never useful later”; it means “not this product’s job.”
4. APZQEP remains infrastructure. Projects may provide delivery context for quality work later — it does not replace APZQEP.

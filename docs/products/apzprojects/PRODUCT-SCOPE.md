APZ Projects **owns** the following business capabilities (product sense — not implementation):

| Capability                    | Meaning                                                                       |
| ----------------------------- | ----------------------------------------------------------------------------- |
| Work planning                 | Define what will be delivered and how it is organised                         |
| Task / work item management   | Capture, assign, prioritise, and lifecycle-manage units of work               |
| Milestone & progress tracking | See whether delivery is on track against agreed checkpoints                   |
| Ownership & accountability    | Clear owners for work, plans, and outcomes                                    |
| Dependency awareness          | Make cross-team and cross-work dependencies visible                           |
| Delivery coordination         | Align people and work so progress is shared, not siloed                       |
| Portfolio / programme view    | Leadership visibility across related delivery efforts (product sense)         |
| Release / outcome linkage     | Connect work to releases, goals, or stated outcomes                           |
| Context for related products  | Provide the shared centre other APZHUB products may relate to when authorised |

Scope is expressed as **what the product is responsible for**, not how it is built.

Define **what is measured**. Do not define dashboards, tooling, or implementation.

## Core KPIs

| Metric                           | Definition (business)                                                                        | Linked outcomes |
| -------------------------------- | -------------------------------------------------------------------------------------------- | --------------- |
| Plan clarity                     | Share of active work with clear owner, status, and target window                             | BO-01, BO-02    |
| On-time commitment rate          | Share of planned milestones / commitments met within agreed window                           | BO-05, BO-10    |
| Risk age                         | Age of open blockers / at-risk items (e.g. median / P90)                                     | BO-03           |
| Status-chasing load              | Qualitative / survey signal of time spent reconstructing progress outside APZ Projects       | BO-06           |
| Cross-team dependency visibility | Share of known dependencies recorded and owned                                               | BO-04           |
| Leadership visibility latency    | Time for a leader to answer “what is at risk?” from the product (qualitative until measured) | BO-07           |
| Work-to-outcome linkage          | Share of active work linked to a stated outcome / release intent                             | BO-08           |
| Cycle time (team-level)          | Elapsed time from work start to done for a defined work unit                                 | BO-05, BO-10    |
| Replan frequency                 | How often commitments materially change without recorded reason (stability signal)           | BO-01, BO-05    |
| Related-product attachment       | Where authorised: share of relevant Time / Support / quality items linked to project context | BO-09           |

## Metric rules

1. Targets and baselines are set after mission approval using real operational data — not invented in this programme.
2. Metrics serve outcomes; they do not justify unrelated feature work.
3. No dashboard design in APZ-PROJECTS-000.

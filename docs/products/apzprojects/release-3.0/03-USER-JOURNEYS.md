## This document must NOT be

Abstract swimlanes without emotion or interruption.

## This document MUST be

Lived sequences. Example frame:

> Monday morning. The project manager logs in. What happens?  
> Every click. Every thought. Every interruption. Everything.

For each journey include:

- Trigger (time, event, anxiety)
- Steps (screen-level, not “uses system”)
- Decisions and hesitations
- Interruptions (chat, meeting, escalation)
- Failure paths
- What “relief” looks like at the end
- Where Enterprise Context should appear without being asked

## Design Support note

After each journey lands, Cursor maps steps → existing screens / missing screens / reuse / effort — in `design-support/`.

## Highlights

- **Operational Workspace** — queue, delivery portfolio, operational changes, mobile ops tabs
- **Project Cockpit** — intent navigation (overview · delivery · planning · control · history)
- **Lifecycle** — initiation wizard, readiness gates, close wizard, baselines
- **Portfolio** — scorecard, workspace, timeline, programme/initiative nodes
- **Teams & resource** — directory, team surface, delivery signals
- **Collaboration** — contextual panels without SoR duplication
- **Reporting & reviews** — operational reports catalogue and review calendar
- **Search & productivity** — Projects search, shortcuts, saved searches
- **Administration** — governance profiles, policies, delegations, retention, roles, audit
- **Enterprise Context** — composed context; Systems of Record attributed
- **Hardening** — a11y (WCAG axe critical/serious = 0 on core surfaces), performance within budget, security review, cross-platform smoke, operational readiness

## What Release 3.0 is not

- Not a Plane / Jira / Monday clone — enterprise language and APZHUB shell only
- No new 3.0 features after close — baseline behaviour frozen

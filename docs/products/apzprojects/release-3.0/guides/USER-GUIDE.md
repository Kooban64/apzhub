# APZ Projects 3.0 — User Guide

| Audience | Project managers · PMO · programme managers · delivery leads |
| -------- | ------------------------------------------------------------ |
| Product  | APZ Projects Release 3.0                                     |

## Getting started

1. Sign in to APZHUB (single SSO).
2. Open **APZ Projects** from the Activity Bar / sidebar.
3. Land on the **Operational Workspace** (`/workspace/projects`).

## Operational Workspace

- **Queue** — decisions, attention, waiting
- **Delivery Portfolio** — strips with health and confidence
- **Operational Changes** — what changed that matters
- **Mobile** — Queue / Portfolio / Changes tabs

Use **Quick Action** for create project or open directory. Press **Escape** to dismiss the menu.

## Project Cockpit

Open a project from the portfolio or All Projects list.

Focus intents:

| Intent   | Use for                                 |
| -------- | --------------------------------------- |
| Overview | Pulse, health, lifecycle, shell edit    |
| Delivery | Commitments, waiting, milestones, tasks |
| Planning | Roadmap / planning surfaces             |
| Control  | Risks, decisions, actions               |
| History  | Operational changes                     |

## Initiate a project

`/workspace/projects/new` — staged wizard (classification, governance, template, success criteria). Steps expose `aria-current="step"` for the active stage.

## Search & productivity

- Search: `/workspace/projects/search`
- Command Palette: **Ctrl+Shift+P** (Windows/Linux) · **⌘+Shift+P** (macOS)
- Help / settings: sidebar Help and Settings

## What you will not see

- Plane / Jira / engine branding or raw backend role names
- Module-to-module shortcuts that bypass Platform Services

## Feedback

Operational learning drives Release 3.1 — raise friction through APZHUB Product Learning channels, not ad-hoc 3.0 behaviour changes.

# AI Considerations — APZQEP-ARCH-007

> Companion extract. Authoritative detail: [TRACEABILITY-ARCHITECTURE.md](./TRACEABILITY-ARCHITECTURE.md) §15.

## Rules

1. **AI consumes Traceability** — may read Trace Links, coverage, and impact explanations.
2. **AI never owns Traceability** — cannot be Trace Authority for authoritative links.
3. AI-proposed links use `origin = ai_suggestion` and provisional/inferred confidence.
4. Promotion to active/approved requires human or governed system authority.
5. AI citations must reference Trace / Relationship identifiers.
6. **No auto-certification** from AI or connectivity.

No AI implementation is authorised by APZQEP-ARCH-007.

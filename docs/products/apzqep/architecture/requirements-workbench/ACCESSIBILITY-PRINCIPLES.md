# Accessibility Principles — APZQEP-ARCH-006

> Companion extract. Authoritative detail: [REQUIREMENTS-WORKBENCH-ARCHITECTURE.md](./REQUIREMENTS-WORKBENCH-ARCHITECTURE.md) §14.

## Binding principles

1. Keyboard-complete operation for primary workflows.
2. Visible focus and labelled regions (Explorer, Main, Inspector, Relationship, Activity).
3. Screen-reader announcements for validation and selection changes.
4. Colour never sole encoding of lifecycle, conflict, or immutability.
5. Virtualisation + countable navigation for large Requirement sets.
6. WCAG AA target for Workbench chrome and content.
7. Graph mode (future) must provide list equivalent at all times.

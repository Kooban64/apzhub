# User Workflow Architecture — APZQEP-ARCH-006

> Companion extract. Authoritative detail: [REQUIREMENTS-WORKBENCH-ARCHITECTURE.md](./REQUIREMENTS-WORKBENCH-ARCHITECTURE.md) §16.

## Canonical workflows

1. **Author** — Create Requirement → Edit → Save → Relate → Lifecycle submit/review.  
2. **Analyse impact** — Select → Relationship Explorer outbound → optional graph lens → split open dependents.  
3. **Resolve conflict** — Conflicts filter → Inspector → rationale / lifecycle action.  
4. **Freeze configuration** — Pin Content Versions → Baseline draft → lock → integrity.  
5. **Compare releases** — Baseline compare → version-changed → Content Version diff.  
6. **Historical review** — Open immutable Content Version / retired Relationship → read-only.

Each workflow must keep the user inside the Workbench grammar without full-page navigational resets.

# Domain Ownership — APZQEP-ARCH-009

> Companion extract. Authoritative detail: [VERIFICATION-ARCHITECTURE.md](./VERIFICATION-ARCHITECTURE.md) §3.

## Verification owns

Verification Records · Decisions · Status · History · Authority · Rationale · Metadata · Context · Lifecycle · Policies · Events

## Verification does not own

Requirements · Trace Links · Relationships · Evidence · Test Cases · Test Specifications · Executions · Certification · Coverage · Impact

## Hard rules

- One SoR per concern.
- Verification stores governed references to foreign artefacts.
- Foreign domains consume Verification outcomes; they do not redefine them.

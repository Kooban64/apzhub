# APZ QEP — Long-Term Commitments

> **Programme:** APZQEP-CONSTITUTION-001  
> **Authority:** Constitutional (Article IX)  
> **Horizon:** Multi-year; stable intent

## Commitments

| Commitment                         | Meaning                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| **Enterprise Quality Engineering** | We commit to the QE category — not a temporary TCMS rebrand                     |
| **Evidence-first Engineering**     | Evidence remains first-class in product and process                             |
| **Continuous Certification**       | Certification is a core, evolving capability — not a report add-on              |
| **Governed AI**                    | AI remains assistant-class with audit, human gates, and provider replaceability |
| **Platform Integration**           | Native APZHUB Platform consumption and contribution — not a siloed app          |
| **Knowledge-driven Quality**       | Knowledge bases, templates, and libraries compound organisational quality       |
| **Open Standards**                 | Prefer REST, webhooks, MCP (or successors), and documented contracts            |
| **Extensible Architecture**        | New connectors/providers/agents via Integration SDK without SoR redesign        |

## Commitments to customers and operators

1. Self-hosted / data-control paths remain first-class where practical.
2. Backward compatibility of public APIs where practical; breaking changes versioned and documented.
3. Certification and privileged audit history preserved per policy.
4. Brand masking of backend engines for standard users.
5. Known limitations published per release.

## Commitments we explicitly do not make

| Non-commitment                         | Reason                                    |
| -------------------------------------- | ----------------------------------------- |
| Eternal feature parity with every TCMS | Dilutes strategy                          |
| Permanent single AI vendor             | Violates AI Constitution                  |
| Becoming CI/ALM/device cloud           | Violates Product Guardrails               |
| Auto-certification                     | Violates Certification & AI Constitutions |

## Relationship to roadmap

Roadmaps may sequence delivery; they may not abandon these commitments without Owner amendment of this Constitution.

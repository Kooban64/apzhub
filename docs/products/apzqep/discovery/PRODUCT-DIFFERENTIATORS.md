# APZ QEP — Product Differentiators

> **Programme:** APZQEP-DISCOVERY-001  
> **Rule:** Differentiate intentionally. Do not chase every competitor feature.

## Differentiator portfolio

| Opportunity                           | Intentional differentiate? | Why                                                        |
| ------------------------------------- | -------------------------- | ---------------------------------------------------------- |
| **Quality Intelligence**              | Yes                        | Move beyond pass-rate dashboards to decision-grade insight |
| **Verification Engineering**          | Yes                        | Verification as engineered asset (not only case lists)     |
| **Continuous Certification**          | **Yes — flagship**         | Underserved; aligns REQ-001 & philosophy                   |
| **Evidence-first engineering**        | Yes                        | Evidence before opinion; audit-ready by design             |
| **Quality Knowledge Base**            | Yes                        | Reusable playbooks ground humans and AI                    |
| **AI Quality Agents**                 | Yes                        | Assistants with gates; never SoR                           |
| **Verification maturity model**       | Yes                        | Productised journey L1→L6                                  |
| **Enterprise governance**             | Yes                        | Platform IAM, audit, tenant, Zero Trust                    |
| **Certification readiness**           | Yes                        | Release go/no-go as first-class                            |
| **Risk-based quality**                | Yes                        | Risk drives coverage priority                              |
| **Executive quality intelligence**    | Yes                        | C-level portfolio risk, not only QA ops                    |
| **Natural language quality querying** | Yes (phased)               | Permission-filtered NL over SoR                            |
| **Knowledge-driven AI**               | Yes                        | AI grounded in KB + SoR, not generic LLM                   |
| **MCP-native architecture**           | **Yes — flagship**         | Governed IDE/agent channel                                 |
| **IDE-native workflows**              | Yes                        | Cursor/VS Code/etc. without bypassing SoR                  |
| **Platform-first architecture**       | **Yes — structural**       | APZHUB native; suite adjacency                             |

## What we will not differentiate on (by design)

| Area                               | Stance                  |
| ---------------------------------- | ----------------------- |
| Cheapest SMB seat price            | Avoid race to bottom    |
| Being a Jira plugin                | Optional sync only      |
| Replacing Playwright/Cypress/JUnit | Orchestrate/ingest only |
| Device/browser cloud               | Not BrowserStack        |
| Unrestricted autonomous AI certify | Explicitly rejected     |

## Differentiator narrative (external)

> APZ QEP is the enterprise System of Record for quality — from approved requirements through verification and evidence to human-certified release readiness — with AI assistants and IDE agents that are powerful, interchangeable, and never in control.

## Implication for Definition

Prioritise Definition stories that make Continuous Certification, Evidence-first, Platform-first, and MCP-governed AI **visible and believable**, while covering commodity TCMS parity enough to be credible.

# APZ QEP — Long-Term Product Strategy

> **Programme:** APZQEP-DISCOVERY-001  
> **Horizon:** Five years (strategic intent — not a delivery commitment schedule)

## Five-year vision

By year five, APZ QEP is recognised as the **enterprise System of Record for Quality Engineering**: organisations manage requirements-linked verification, evidence, risk, and continuous certification on APZHUB, with AI agents and IDEs accelerating work under strict human accountability.

## Enterprise positioning

| Position         | Statement                                                     |
| ---------------- | ------------------------------------------------------------- |
| Category         | Enterprise Quality Engineering Platform (not TCMS)            |
| Beachhead        | APZHUB suite customers + regulated/audit-heavy mid-enterprise |
| Enemy (category) | Fragmented tools + ungoverned AI test generation              |
| Not competing as | Cheapest SMB TCMS · Jira plugin · device cloud · test runner  |

## Commercial strategy

| Element                | Strategy                                                     |
| ---------------------- | ------------------------------------------------------------ |
| Editions               | Starter / Professional / Enterprise                          |
| Anchors                | Seats + projects + automation volume + AI usage entitlements |
| Beachhead monetisation | Suite uplift + standalone enterprise licenses                |
| Services               | Implementation, migration from TCMS, training                |
| Avoid                  | Race-to-bottom pricing against Tuskr-class                   |

## Innovation strategy

1. **Governed AI before flashy AI** — audit, prompts, providers, flags first.
2. **MCP-native client class** — treat agents as first-class, controlled clients.
3. **Continuous certification** as lasting moat.
4. **Knowledge-driven quality** — KB compounds switching costs ethically.
5. Sequence Future Innovation via Owner programmes — no scope creep in MVP.

## Platform strategy

- Remain native on Certified APZHUB Platform (1.4 baseline; later platforms only under Approval).
- Consume Identity, Authz, Audit, Search, Documents, Notifications, Observability.
- Extend via Integration SDK connectors — never module→engine.
- Preserve Platform freezes unless Platform Owner unlocks.

## AI strategy (strategic)

- AI-native product posture; runtime OFF until authorised.
- Interchangeable providers; self-hosted preference.
- Human approval; never SoR; never auto-certify.
- Detail: AI-DISCOVERY + REQ AIR-*.

## Marketplace strategy

| Phase     | Intent                                                  |
| --------- | ------------------------------------------------------- |
| Near      | Internal libraries/templates                            |
| Mid       | Partner connectors                                      |
| Long (P3) | Marketplace for templates, knowledge packs, agent packs |

## Partner strategy

- System integrators for enterprise rollout
- Connector partners for ALM/CI
- AI/infra partners under DPA and Owner Approval
- Do not partner in ways that reintroduce engine brands into UX

## Open ecosystem strategy

- Versioned public APIs & webhooks
- MCP tool catalogue (documented, allowlisted)
- Runner-agnostic result schemas (JUnit/Playwright/Cypress ingest)
- Prefer open protocols over proprietary IDE lock-in
- Kiwi/other TCMS as SoR: **out of scope**

## Strategic sequencing (years)

| Year | Theme                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------- |
| Y1   | Credible QE SoR: structured verification, evidence, certification, platform governance; CI ingest |
| Y2   | Governed AI + MCP IDE workflows; risk; KB; broader ALM/CI                                         |
| Y3   | Continuous verification/certification maturity; executive intelligence                            |
| Y4   | Marketplace/partners; deeper multi-agent QE                                                       |
| Y5   | Category leadership narrative: continuous certification + governed AI quality platform            |

## Success measures (strategic)

- Enterprise wins citing certification/audit/AI governance
- % APZHUB suite customers adopting QEP
- Reduction in unaudited AI-generated test sprawl (qualitative + metrics later)
- Certification cycle time improvement
- Zero auto-certify incidents

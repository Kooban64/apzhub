## Highlights

- **Enterprise Quality Baseline** — production-ready quality platform for the APZHUB portfolio
- **Quality Flow Workspace** — flagship operational command centre over Continuous Quality Orchestration
- **Durable Systems of Record** — Postgres persistence for Automation, SCM, Quality Intelligence, Dashboards, and Orchestration
- **Cap A–F** — Suites, Execution Plans, Execution Workspace, Defects, Requirements Traceability, Reporting (packages 1.0.0)
- **Waves 1–5** — Automation · SCM · Quality Intelligence · Dashboards · Orchestration (architecture frozen; production durability closed)
- **Fail-closed Cap RBAC** — session permission gates on V1.1 APIs; tenant binding; evidence security enforcement
- **Hardening** — functional regression, accessibility (axe critical/serious = 0), performance within budget, security, operational readiness

## What Version 1.1 is not

- Not a redesign of Wave 1–5 foundations
- Not Wave 6 / APZQEP-166 / external AI providers (not authorised)
- Project membership attribute ACL deferred to Version 1.2 (Owner-approved)
- No new V1.1 features after close — baseline behaviour frozen

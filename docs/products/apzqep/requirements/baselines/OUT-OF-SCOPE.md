# Out of Scope — ENG-020E (Parts 1–3)

Parts 1–3 deliver domain, persistence, application, API, integrity, and Workbench
UI. The programme still excludes:

- verification, execution, evidence, certification, and traceability domain
  capabilities that consume baselines (future programmes)
- relationships, AI, and MCP integration
- clone, unlock, restore, delete, merge, and import/export
- baseline search indexing beyond what the shared Requirements search provider
  already covers

The delivered contracts and UI do not imply that these excluded capabilities are
available.

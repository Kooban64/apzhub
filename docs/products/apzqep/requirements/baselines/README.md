# APZQEP-ENG-020E — Requirement Baselines

> **Status:** ACCEPTED / CLOSED / COMPLETE  
> Owner Acceptance recorded 2026-07-26. Next programme (**APZQEP-ENG-020F** — Requirements Relationship Model) is **PLANNING ONLY**.

Requirement Baselines are a configuration-management aggregate: a named,
numbered, tenant-scoped set of immutable requirement content-version
references, with cryptographic integrity fingerprinting (Part 3) protecting
locked and archived membership against tampering.

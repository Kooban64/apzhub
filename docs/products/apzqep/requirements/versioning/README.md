# APZQEP-ENG-020D — Requirement Content Versioning

> **Status:** IMPLEMENTED / AWAITING OWNER ACCEPTANCE

This pack defines append-only content history for Requirements. `RequirementVersion` means the existing semantic version; `RequirementContentVersion` means immutable content history. No generic versioning engine, baselines, relationships, or AI capability is introduced.

See the linked documents in this directory for model, API, security, operational, and acceptance details.

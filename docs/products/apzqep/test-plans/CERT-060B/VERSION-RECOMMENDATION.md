| Field       | Value                                                                     |
| ----------- | ------------------------------------------------------------------------- |
| Package     | `@apzhub/qep-test-plans`                                                  |
| Current     | **0.2.0**                                                                 |

## Rationale

1. **0.2.0** already denotes Domain + Infrastructure layers in the package.
2. SemVer **1.0.0** remains reserved for first stable **capability** baseline after Workbench + Capability Certification (CERT-050D / CERT-040D pattern).
3. Domain Component Certification retained **0.1.0**; Infrastructure Component Certification should not imply capability completeness.
4. Recorded limitations further counsel against major promotion.

## Owner effect upon Acceptance of this recommendation

- Package remains **0.2.0**.
- May be labelled **Infrastructure Component CERTIFIED** in governance records.
- Capability Freeze / 1.0.0 remain unauthorised.

# APZQEP-OES-ARCH-013 — APPENDIX A — Glossary

| Term                     | Definition                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Test Plan**            | Governed aggregate representing an executable collection of Test Specifications for a scoped validation activity |
| **Plan Item**            | Membership of a Specification (or future Case) within a Plan                                                     |
| **Plan Scope**           | Catalogue class describing planning context (Release, Sprint, Regression, …)                                     |
| **Plan Status**          | Lifecycle state of the Plan aggregate                                                                            |
| **Execution readiness**  | Server-authoritative indication that a Plan may enter In Execution                                               |
| **Test Specification**   | Frozen capability — design blueprint; referenced by Plan Items                                                   |
| **Test Execution / Run** | Future capabilities — own run results; reference Plans                                                           |
| **availableActions**     | Server-computed permitted actions for the current principal (future ENG)                                         |
| **ARCH-013**             | This Capability Architecture programme                                                                           |
| **OES-ARCH-013**         | This Owner Engineering Specification pack                                                                        |

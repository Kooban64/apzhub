## Definition (normative summary)

A **Test Plan** is an executable collection of **Test Specifications** organised to validate a release, product, feature, milestone, sprint, regression cycle, or certification activity.

Test Plans is the SoR for Plan records, Plan Items, Plan Scope, Plan Status/lifecycle, ownership/assignment/scheduling metadata, version lineage, and plan-owned history. It references — and does not redefine — frozen Requirements, Traceability, Verification, and Test Specifications.

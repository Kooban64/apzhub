# Matrix — APZQEP-ENG-030C

Presentation-only Trace Matrix per ARCH-008 [MATRIX-MODEL.md](../../architecture/traceability-workbench/MATRIX-MODEL.md).

## Behaviour

- Component: `QepTraceMatrixView`
- Route: `/workspace/qep/traceability/matrix`
- Cross-tab of bounded Trace Link samples (cap **20×20**)
- Accessible list fallback when grid is unsuitable
- Cells open authoritative Trace Link detail — Matrix is not SoR

## Explicit exclusions

- **No Coverage calculations or Coverage %**
- No Impact analysis
- No unbounded matrix load
- No graph database

Matrix displays link presence / type cues only; analysis engines remain future programmes.

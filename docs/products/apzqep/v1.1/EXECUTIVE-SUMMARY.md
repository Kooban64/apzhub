# Executive Summary — APZQEP v1.1

## Ask

Approve the APZQEP **v1.1 Product Planning pack** so engineering can later begin under discrete, Owner-authorised programmes — not as an unbounded “build v1.1” effort.

## Where we are

APZQEP **v1.0 is complete**:

- Foundation chain certified and frozen: Requirements → Traceability → Verification → Test Specifications → Test Plans
- Expansion delivered under Limited Availability: **Test Execution 1.0.1**, **Evidence 1.0.0**
- Governance, lifecycle, release discipline, and portfolio standards are in force
- Close: **APZQEP-CLOSE-001** · Portfolio governance: **APZHUB-FOUNDATION-002**

v1.0 is a strong **quality-engineering foundation**. It is not yet a full enterprise QE platform comparable to TestRail / Xray / Zephyr / qTest / Tuskr / Testmo / Azure Test Plans.

## Where v1.1 should go

**Theme:** _From foundation to operating platform_

v1.1 makes APZQEP usable as the daily system of work for QA, engineering, and release stakeholders — without rewriting v1.0.

### Recommended v1.1 outcomes

1. **Close Limited Availability gaps** that block trust (Evidence durable storage decision path; TE operational browser readiness; event publication)
2. **Complete the test operating model** — Test Runs, Test Suites, Defects (native)
3. **Unify discovery** — Search across all QEP entities; command palette actions; notifications on QEP events
4. **Ship the first AI value slice** — guarded assistants for requirement analysis, test generation draft, evidence summary, release readiness — always human-approved
5. **Executive & role dashboards** — QA / Tester / Release readiness views (not vanity metrics)

### Explicitly later (1.2+)

- Full Coverage & Impact engines
- Broad ALM connectors (Jira/Azure DevOps deep sync)
- Unrestricted GA for Evidence/TE (separate Owner gate)
- Portfolio multi-product quality scorecards
- Autonomous AI agents without human approval

## Investment shape

| Horizon | Focus                                                                          | Nature             |
| ------- | ------------------------------------------------------------------------------ | ------------------ |
| **1.1** | Operability + Runs/Suites/Defects + Search/Notify + AI assist MVP + Dashboards | Highest user value |
| **1.2** | Coverage, Certification Engine, Integrations depth, Analytics                  | Enterprise depth   |
| **1.3** | Compliance hardening, advanced AI evaluation, GA readiness programmes          | Assurance          |
| **2.0** | Portfolio QE, multi-product intelligence, platform-scale AI                    | Strategic          |

## Governance stance

- Engineering **only** after Owner approval of this pack
- Delivery via **independently closable programmes** (Lifecycle Standard)
- AI under **guardrails + human approval** (AI Operational Framework)
- No foundation/governance redesign inside APZQEP-110

# Product Rule — Defect is an Investigation Record

| Field      | Value                                   |
| ---------- | --------------------------------------- |
| Status     | **IN FORCE**                            |
| Authority  | Product Board (APZQEP-140-D AUTHORISED) |
| Applies to | APZQEP-140-D onward                     |

```text
Execution Results remain the immutable record of what happened.

Evidence remains the immutable record of supporting artefacts.

Defects represent the managed investigation, prioritisation and
resolution process that references those immutable records.
```

| Concern           | Role                                           |
| ----------------- | ---------------------------------------------- |
| Execution (Cap C) | Facts — immutable after completion             |
| Evidence Platform | Artefacts — integrity-bearing references       |
| Defects (Cap D)   | Investigation / resolution — mutable lifecycle |

Defects SHALL NOT rewrite execution history or duplicate evidence storage.

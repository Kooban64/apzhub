# Product Rule — Suite · Planning · Execution · Results

| Field      | Value                                       |
| ---------- | ------------------------------------------- |
| Status     | **IN FORCE**                                |
| Authority  | Product Board (post APZQEP-140-A CERTIFIED) |
| Applies to | APZQEP-140-B onward                         |

```text
A Test Suite defines WHAT shall be executed.

Execution Planning defines WHEN, WHERE, HOW and BY WHOM it is intended to be executed.

Test Execution performs the work.

Results record the outcome.
```

| Capability                             | Owns                                                        |
| -------------------------------------- | ----------------------------------------------------------- |
| A — Enterprise Test Suite Management   | WHAT (suites, structure, versions, governance of assets)    |
| B — Enterprise Test Execution Planning | WHEN / WHERE / HOW / BY WHOM (intent, readiness, handoff)   |
| C — Enterprise Test Execution          | Performing the work (steps, results capture)                |
| (Results / reporting surfaces)         | Recording and presenting outcomes (Cap C artefacts + Cap F) |

Capability B must not absorb Capability C execution behaviour.

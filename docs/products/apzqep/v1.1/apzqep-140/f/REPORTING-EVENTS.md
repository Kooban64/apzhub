# Reporting Events

| Event                                | When                 |
| ------------------------------------ | -------------------- |
| `qep.reporting.dashboard_viewed`     | Dashboard opened     |
| `qep.reporting.report_generated`     | Report generated     |
| `qep.reporting.saved_report_created` | Saved report created |
| `qep.reporting.saved_report_updated` | Saved report updated |

Does not publish Cap A–E business events.

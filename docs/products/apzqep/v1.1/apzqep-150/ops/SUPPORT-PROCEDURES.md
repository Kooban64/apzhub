# APZQEP Support Procedures

1. Confirm LIMITED_AVAILABILITY posture with customer/operator.
2. Capture correlation ID from API error envelope.
3. Classify: Platform vs Cap A–F vs ENG legacy surface.
4. For Cap data loss after restart — cite Known Limitations (not a defect).
5. Escalate Release Blockers (RB-001/RB-002) only via Product Board — not field hotfixes that redesign architecture.

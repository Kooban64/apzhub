## Intent

Sell and operate on **outcomes**, not case counts. Dashboards project measured and derived intelligence — never fabricated metrics (OPS-001 rule).

## Audiences

| Dashboard         | Focus                                                                  |
| ----------------- | ---------------------------------------------------------------------- |
| Executive         | Release health, trend, risk, coverage, perf/a11y/security PASS signals |
| Engineering       | Flaky tests, regressions, defects, coverage, mean execution            |
| QA                | Suites, runs, evidence gaps, readiness blockers                        |
| Operations        | Availability of QE platform services, job queues, runner health        |
| Portfolio         | Multi-product quality posture (APZHUB)                                 |
| Release Readiness | Score composition + gate status                                        |

## Rules

1. Structure first; values only when measured.
2. Permission-filtered projections.
3. Wave 4 primary delivery; thin readiness views may appear earlier if evidence exists.

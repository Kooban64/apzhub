# CORRELATION-MODEL — QO-005

Relationships are registered in a provider-neutral knowledge base.

## Asset types

repositories, services, modules, packages, components, requirements, test suites, execution plans, automation assets, evidence, defects, historical failures, quality signals, releases, documentation, dependencies, plus change seeds (file/commit/branch/…).

## Relationship kinds

`contains`, `depends_on`, `implements`, `covers`, `validates`, `produces`, `related_to`, `regresses`, `documents`, `derived_from`.

Every relationship carries `reason`, `strength`, and optional `evidenceRefs` for explainability.

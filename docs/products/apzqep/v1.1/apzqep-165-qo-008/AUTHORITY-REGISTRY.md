# Authority Registry

Catalogue of authority definitions.

| Field              | Description                        |
| ------------------ | ---------------------------------- |
| Authority ID       | Stable key                         |
| Authority Name     | Display name                       |
| Scope              | Optional organisational scope hint |
| Delegation Support | Whether decisions may be delegated |
| Escalation Support | Whether escalations are permitted  |
| Metadata           | Free-form                          |

The registry does **not** manage identities, membership, or RBAC. It references authorities only.

# Separation of Duties

Declarative governance rules — **not** procedural workflow logic.

| Rule                    | Meaning                                              |
| ----------------------- | ---------------------------------------------------- |
| Independent Approval    | Distinct actors across authorities                   |
| Two-Person Approval     | Minimum two distinct actors for positive coverage    |
| No Self Approval        | Declared actor cannot approve as self-subject        |
| Mandatory Product Board | Product Board authority must decide                  |
| Mandatory CAB           | CAB authority must decide                            |
| Emergency Authority     | Named emergency authority may override pending state |
| Time-Limited Delegation | Delegations carry expiry; expired delegations void   |

Rules are evaluated against the decision set already recorded. No BPMN, no step machine, no workflow engine.

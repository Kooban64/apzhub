# Decision Model

| Concept          | Meaning                                                                   |
| ---------------- | ------------------------------------------------------------------------- |
| Decision         | Platform conclusion from completed governance outputs                     |
| Approval         | Authorised human acceptance/rejection (QO-008) — distinct                 |
| Decision Package | Immutable SoR for the platform conclusion                                 |
| Decision Profile | Threshold set that shapes outcome derivation                              |
| Outcome          | Advisory: GO / CONDITIONAL_GO / NO_GO / DEFERRED / SUPERSEDED / CANCELLED |

The engine **composes**; it does not re-evaluate policies, gates, or approvals.

# Event Integration

All publications go through the QO-010 Event Backbone.

| Event Type                 | Meaning                                |
| -------------------------- | -------------------------------------- |
| source.identity.normalized | A source identity was normalized       |
| source.change.associated   | Changes associated with a Quality Flow |
| source.package.created     | Source Change Package created          |
| source.package.updated     | New package supersedes a prior package |

Past-tense facts only. No command events.

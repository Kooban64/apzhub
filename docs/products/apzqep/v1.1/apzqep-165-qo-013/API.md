# API — Quality Intelligence Enrichment

Surface: `orchestration.enrichment` (DI: `orchestration.enrichment.engine`).

| Operation                 | Purpose                            |
| ------------------------- | ---------------------------------- |
| Create Enrichment Package | Refs + advisory insights → package |
| Read Enrichment Package   | Fetch by id                        |
| Query Advisory Insights   | Insights on a package              |
| Read Historical Signals   | Trend / signal / statistical refs  |
| Read Enrichment History   | Audit trail                        |
| Diagnostics               | Counts, distributions, health      |

No decision APIs. No governance APIs. No upstream mutation APIs.

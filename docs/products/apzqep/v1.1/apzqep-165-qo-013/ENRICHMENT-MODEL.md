# Enrichment Model

| Principle                 | Rule                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| Additive                  | Enrichment attaches insight; never edits history                     |
| Non-corrective            | Disagreement with a Decision Package yields advisory commentary only |
| Reference, don't replace  | Every enrichment points at upstream SoRs                             |
| AI optional & advisory    | External AI never becomes a system of record                         |
| Provider-neutral contract | Rules / historical / statistical / future AI share one contract      |

Authoritative vs advisory hierarchy remains locked: Decision Package / Governance / Approval / etc. stay SoRs; Enrichment Package is advisory only.

# Event Integration

All publications go through the QO-010 Event Backbone.

| Event Type                   | Meaning                                   |
| ---------------------------- | ----------------------------------------- |
| advisory.insight.attached    | An advisory insight was attached          |
| quality.enrichment.created   | Enrichment activity created               |
| enrichment.package.created   | Enrichment Package created                |
| quality.enrichment.completed | Enrichment completed (upstream unchanged) |

Past-tense facts only. No command events.

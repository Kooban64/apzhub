# Report Profiles

Immutable declarative profiles define **inclusion criteria only**. Presentation is external.

| Kind                   | Purpose                                      |
| ---------------------- | -------------------------------------------- |
| `developer`            | Developer-facing evidence chain              |
| `pull_request`         | PR/MR-oriented references                    |
| `regression`           | Regression / automation / enrichment refs    |
| `executive`            | Executive decision / governance / enrichment |
| `production_readiness` | Production readiness chain                   |
| `compliance`           | Governance, approval, audit                  |
| `audit`                | Full slot coverage                           |
| `custom`               | Caller-supplied inclusion slots              |

Profiles do not hardcode presentation, layout, or rendering.

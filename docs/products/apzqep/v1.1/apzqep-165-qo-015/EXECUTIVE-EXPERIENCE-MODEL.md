# Executive Experience Model

## Principles

1. **Projection, not presentation.** Defines what executives should see — not how it is rendered.
2. **Executives consume decisions.** They never become part of the decision pipeline.
3. **References only.** Never duplicates authoritative artefacts.

## Separation

| Layer                     | Owner                                      |
| ------------------------- | ------------------------------------------ |
| Information architecture  | QO-015 Executive Experience                |
| Presentation architecture | APZQEP-164 Dashboard & Quality Experience  |
| Delivery channels         | External (web, mobile, PDF, email, Teams…) |

## Persistence

Uses existing orchestration in-memory persistence. Future durable Executive Experience
persistence is deferred and must remain reference/projection-only.

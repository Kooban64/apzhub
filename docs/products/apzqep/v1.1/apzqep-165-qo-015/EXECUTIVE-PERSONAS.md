# Executive Personas

Immutable declarative personas define **consumption preferences only**.

| Kind                  | Focus                                    |
| --------------------- | ---------------------------------------- |
| `ceo`                 | Outcomes and decision posture            |
| `cio`                 | Technology risk / readiness / governance |
| `cto`                 | Engineering quality posture              |
| `head_of_engineering` | Delivery quality and coordination        |
| `qa_director`         | QA posture across flows                  |
| `compliance_officer`  | Compliance and audit consumption         |
| `product_board`       | Product board decision / readiness       |
| `programme_manager`   | Programme-level quality flow consumption |
| `custom`              | Caller-supplied preferences              |

Personas select Report Profiles and artefact slots. They never render UI.

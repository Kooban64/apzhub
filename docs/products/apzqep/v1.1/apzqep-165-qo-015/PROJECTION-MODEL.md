# Projection Model

Defines **what** an executive should see:

- Included artefacts (opaque refs by slot)
- Report profile selection
- Navigation preferences
- Information priority
- Grouping / filters / presentation hints

## Guards

| Flag             | Value  |
| ---------------- | ------ |
| `projectionOnly` | `true` |
| `rendersNothing` | `true` |

No rendering. No metrics. No report generation. Wave 4 dashboards may consume projections.

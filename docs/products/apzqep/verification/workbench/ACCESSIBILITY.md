# Accessibility — APZQEP-ENG-040C

- Keyboard-operable filters, tables, and decision dialogs
- `role="dialog"` / `aria-modal` on confirmations
- Status badges accompanied by text (not colour-only)
- Breadcrumbs / region labels / `sr-only` table captions
- Focusable action buttons gated by `availableActions`
- Aligns WCAG AA targets of Design System **006**

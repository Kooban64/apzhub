# Explorer — APZQEP-ENG-040C

List-first inventory of Verification Records.

## Supported

- Sorting (updated / created / priority / status)
- Filtering (status, outcome, subject kind)
- Saved views (local preference references)
- Grouping (status / priority / assignee)
- Pagination (page size 50)
- Scroll container for long lists
- Bulk selection checkboxes
- Status, priority, ownership, version indicators

## Data

`GET /api/v1/qep/verifications` via `listVerifications`.

## Core KPIs

| Metric                          | Definition (business)                                                        | Linked outcomes |
| ------------------------------- | ---------------------------------------------------------------------------- | --------------- |
| Average first response time     | Mean time from request opened to first meaningful reply                      | BO-01, BO-04    |
| Average resolution time         | Mean time from request opened to resolved                                    | BO-02           |
| SLA achievement                 | Share of requests meeting agreed response / resolution commitments           | BO-05           |
| Backlog age                     | Age distribution of open requests (e.g. median / P90 age)                    | BO-06, BO-07    |
| Requester satisfaction          | Post-resolution satisfaction score (or equivalent survey signal)             | BO-09           |
| Agent productivity              | Resolved volume relative to available agent capacity (period-based)          | BO-07, BO-08    |
| Escalation rate                 | Share of requests escalated beyond first-line ownership                      | BO-03, BO-07    |
| First-contact resolution rate   | Share resolved without transfer / reopen cycle                               | BO-03           |
| Reopen rate                     | Share of resolved requests reopened within a defined window                  | BO-03, BO-09    |
| Abandoned / silent channel rate | Share of help still handled outside APZ Support (qualitative until measured) | BO-08           |

## Metric rules

1. Targets and baselines are set after mission approval using real operational data — not invented in this programme.
2. Metrics serve outcomes; they do not justify unrelated feature work.
3. No dashboard design in APZ-SUPPORT-000.

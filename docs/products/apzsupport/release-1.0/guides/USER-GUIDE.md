# APZ Support — User Guide (v1.0)

## Daily path

1. Open **APZ Support** → **Requests**.
2. Create a request or open an existing one.
3. Use **Conversation** for customer replies and internal notes.
4. Update status / ownership; **Close** when resolved.

## Limits

- Attachments: max **1 MiB**; delete is not available.
- Live updates are not enabled — refresh the list or detail to see changes.
- Help → **Current limitations** restates these rules.

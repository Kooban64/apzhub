# APZ Time — User Guide (v1.0)

1. Open **APZ Time** Overview (`/workspace/time`).
2. Open **Timesheets** to list tracked time.
3. Create a timesheet; attach activity, customer, and tags when relevant.
4. Stop or archive when work is complete.
5. Use **Help** for product identity and current limitations.

Approvals and reporting UI are not part of v1.0. Prefer APZHUB product language — not engine names.

## Core KPIs

| Metric                        | Definition (business)                                                                       | Linked outcomes |
| ----------------------------- | ------------------------------------------------------------------------------------------- | --------------- |
| Journey coverage              | Share of priority cross-product processes with a governed Workflow journey                  | BO-01, BO-05    |
| Step ownership clarity        | Share of active journey steps with a named owner                                            | BO-02           |
| Handoff wait time             | Elapsed time between step ready and step started (sample)                                   | BO-03           |
| Informal-bypass incidence     | Observed work progressing outside the defined journey when a journey should apply           | BO-01, BO-05    |
| Journey visibility latency    | Time for a lead to answer “where is this in the journey?” (qualitative until measured)      | BO-04           |
| Backbone attachment           | Share of journey steps that reference Projects / Support / Time / Documents / quality by ID | BO-05, BO-10    |
| Coordination load             | Survey / observation signal of time spent reconstructing handoffs outside APZHUB            | BO-07           |
| Journey completion rate       | Share of started journey instances that reach a defined complete state                      | BO-03, BO-09    |
| Auditability                  | Share of completed journeys with complete step history                                      | BO-08           |
| Intent vs execution confusion | Incidents of users encountering automation-engine UX or branding                            | BO-06           |

## Metric rules

1. Targets and baselines are set after mission approval using real operational data — not invented in this programme.
2. Metrics serve outcomes; they do not justify unrelated feature work.
3. No dashboard design in APZ-WORKFLOW-000.

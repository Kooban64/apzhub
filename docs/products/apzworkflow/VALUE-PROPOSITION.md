## Why organisations should use APZ Workflow

APZ Workflow is the APZHUB orchestration capability: one trusted place to define and follow the business journeys that connect Projects, Support, Time, Documents, and quality — without turning the organisation into an automation-console culture.

## Value pillars

| Pillar                 | Proposition                                                                 |
| ---------------------- | --------------------------------------------------------------------------- |
| **Intent**             | Journeys express what should happen next in business language               |
| **Glue**               | The four Reference Implementations work as one operating system             |
| **Accountability**     | Steps have owners; progress is visible                                      |
| **Discipline**         | Orchestration stays separate from automation execution                      |
| **Portfolio leverage** | Analytics and Law can later consume journey context without rebuilding glue |

## What we do not claim here

This face does not list features, compare vendors, or describe how the product is built. Value is stated as **business benefit**.

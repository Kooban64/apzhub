## Principle

> **Context is composed, never duplicated.**

## Standing sentence (protect for years)

> **Enterprise value is created by composing trusted context, not by duplicating enterprise truth.**

## What this means

| Do                                        | Do not                                          |
| ----------------------------------------- | ----------------------------------------------- |
| Compose references from Systems of Record | Copy operational data into a ninth SoR          |
| Show context where work happens           | Force users to navigate away to understand work |
| Preserve product ownership                | Synchronise duplicate truth across products     |
| Present via panel, API, mobile, AI, …     | Treat the first UI as the capability            |

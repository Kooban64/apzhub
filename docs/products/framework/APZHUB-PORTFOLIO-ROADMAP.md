Rules for expansion:

1. Start from [APZHUB-ENTERPRISE-PORTFOLIO-BASELINE.md](./APZHUB-ENTERPRISE-PORTFOLIO-BASELINE.md)
2. Choose candidates from [APZHUB-ENTERPRISE-DOMAIN-STRATEGY.md](./APZHUB-ENTERPRISE-DOMAIN-STRATEGY.md)
3. Score on the Evaluation Matrix — [APZHUB-DOMAIN-SELECTION-METHOD.md](./APZHUB-DOMAIN-SELECTION-METHOD.md)
4. Owner Auth names the domain → Mission → Native Adoption
5. Use the Playbook unchanged; adopt APZQEP
6. Do not redesign Foundation / Quality / Core / Governance Layer to “make room”
7. Update Domain Catalogue · RI map · Product Catalogue only after adoption completes

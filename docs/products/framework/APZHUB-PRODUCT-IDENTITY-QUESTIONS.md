## Practice

Every product carries **one defining identity question** alongside the standard Native Adoption (N-01) audit.

These questions sharpen the Playbook. They do **not** modify it.

## Register

| Product       | Defining identity question                                               | Product-specific audit      |
| ------------- | ------------------------------------------------------------------------ | --------------------------- |
| **Workflow**  | Can the business describe this without mentioning software?              | Workflow Test               |
| **Analytics** | Does the user enter through a business question rather than a dashboard? | Decision Entry              |
| **Law**       | Does governance support work rather than operate separately?             | Governance Companion        |
| **Knowledge** | Does this help people act correctly in context?                          | Organisational Memory Audit |

## Rule

If N-01 cannot answer the defining identity question affirmatively, the product is **not** native yet — regardless of shell polish.

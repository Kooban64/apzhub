## Rule

After every product reaches **Reference Implementation** status, complete a brief retrospective before opening the next Native Adoption programme.

Ask only:

1. Did the Playbook work as written?
2. Did we need to bypass any steps?
3. What operational learning was unique to this product?
4. Did we discover a cross-product pattern?

If (1) is consistently **yes**, that is further evidence the methodology is stable.

Do **not** use the retrospective to invent Playbook changes. Promote only via evidence (Learning Register / EPP / Owner Auth).

## Clarification

> **“Only evidence earns engineering”** applies to **changing the platform you have already built**.  
> It does **not** freeze **completing the approved product portfolio**.

PB-001’s “no new programmes” meant: **no speculative platform programmes**.  
It did **not** mean: stop delivering planned products.

## Two lanes

### Lane 1 — Platform Evolution (evidence-driven)

| Attribute | Value                                                                                                            |
| --------- | ---------------------------------------------------------------------------------------------------------------- |
| Driver    | Operational evidence (OBSERVE-001 → Product Board)                                                               |
| Pace      | Slow · deliberate                                                                                                |
| Examples  | My Work enhancements · Unified Notifications · Executive Workspace · Search · AI · APZQEP changes · architecture |
| Freeze    | **In force** unless confirmed defect, Owner-approved blocker, or Board investment decision                       |

### Lane 2 — Portfolio Delivery (business strategy)

| Attribute | Value                                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------------------- |
| Driver    | Approved portfolio / business roadmap                                                                               |
| Pace      | Steady · planned                                                                                                    |
| Examples  | APZ Documents · APZ Workflow · APZ Analytics · APZ Law Platform                                                     |
| Rule      | Execute Product Mission → Owner Approval → Native Adoption → (optional) RI — **without waiting for pilot friction** |

These lanes run **in parallel**. Portfolio delivery does not unfreeze platform evolution.

## What Cursor may do

## Principle

> **Within APZHUB, one business concept shall have one authoritative meaning.**

No product may redefine an existing enterprise concept.

## Portfolio vocabulary (authoritative)

| Term                                             | Authoritative meaning                                                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| **Workflow**                                     | Business process orchestration (intent)                                                                             |
| **Analytics**                                    | Decision support                                                                                                    |
| **Documents**                                    | Enterprise information                                                                                              |
| **Law**                                          | Governance                                                                                                          |
| **Knowledge** / **APZ Knowledge**                | Organisational memory                                                                                               |
| **Knowledge Discovery**                          | Finding organisational memory                                                                                       |
| **Knowledge Overlay**                            | Contextual presentation of knowledge inside another product                                                         |
| **Learning**                                     | Skills, engineering practice, operational improvement (APZQEP)                                                      |
| **Search**                                       | Retrieval capability                                                                                                |
| **AI Assistant**                                 | Consumer of organisational memory                                                                                   |
| **Enterprise Context** / **Context Composition** | Compose trusted information around work without changing ownership — not a SoR, not “companion” as product identity |

These terms must never be used interchangeably.

**Context Composition Principle:** Context is composed, never duplicated. — [APZHUB-CONTEXT-COMPOSITION-PRINCIPLE.md](./APZHUB-CONTEXT-COMPOSITION-PRINCIPLE.md)

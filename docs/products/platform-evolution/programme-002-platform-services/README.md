## Single objective

> **Make APZHUB feel like one application.**

Not seven products behind a launcher. One Enterprise Work Platform.

---

## Why “Platform Services” (not “Experience”)

These are **shared services** every product consumes. Some are visible; all are shared. They are not product features and not APE Foundation engines inventing new cross-cutting SoRs from scratch — they **compose and elevate** APE capabilities into cohesive platform behaviour.

| Service         | Visible?  | Shared? |
| --------------- | --------- | ------- |
| Unified Search  | Yes       | Yes     |
| Notifications   | Yes       | Yes     |
| Activity Stream | Yes       | Yes     |
| Command Palette | Yes       | Yes     |
| User Presence   | Mostly no | Yes     |
| Preferences     | Yes       | Yes     |
| Saved Views     | Yes       | Yes     |
| Recent Items    | Yes       | Yes     |
| Favorites       | Yes       | Yes     |
| Universal Inbox | Yes       | Yes     |

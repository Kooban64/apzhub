## What is delivered

APZ Platform Engines (APE) elevated and certified for Foundation v1.0:

- Mature engines named and catalogued (Registry, Search, Notify, Events, Integration, Config)
- Substantial engines elevated (Activity, Command, Flags, Realtime SSE)
- **APE-Audit** unified query facade (`@apzhub/platform-audit`, `/api/v1/platform/audit`) — domain audit SoRs retained
- Catalogue API `/api/v1/platform/engines`
- ADR-PE-0001 Platform Owns Behaviour
- Principle: never duplicate a capability; never retrain users

## Out of scope

AI Gateway · RAG · agents · product redesign · UI changes · Delivery Standard amendment.

## Role coverage required

| Role                          | 1.2 involvement                              |
| ----------------------------- | -------------------------------------------- |
| Owner / Enterprise Governance | Accept plan; Approve each delivery programme |
| Platform Engineering Lead     | Sequence, SemVer, architecture gates         |
| Product Owners (per product)  | Scope honesty, acceptance criteria           |
| Integration / Adapter owners  | Support, TCMS, Search publishers             |
| Platform Ops Owner            | OPS themes, restore, coexistence             |
| Security / Compliance Owners  | Continuous hardening, audit                  |
| QA Owner                      | Re-certification evidence                    |
| Customer Success (commercial) | KL communication; no oversell                |

## Capacity principles

1. P0 before P2 — do not starve OPS/SEARCH/TCMS for polish.
2. Prefer one Support CE slice done well over both half-done.
3. No parallel STOP programmes.
4. Host coexistence work is mandatory capacity, not optional.

## External partners

Partner delivery of 1.2 surfaces only after Partner enablement (Commercial Strategy) and only for Accepted packages.

# APZ Documents 1.0.0 — User Guide

> **Product:** APZ Documents  
> **Version:** **1.0.0**  
> **Audience:** End users with Documents permissions  
> **Date:** 2026-07-19

---

## Open Documents

1. Sign in to APZHUB
2. Open **Documents** from the Activity Bar / Sidebar (only if your role allows)
3. Work in `/workspace/documents`

## Typical actions (metadata plane)

| Action            | Description                                             |
| ----------------- | ------------------------------------------------------- |
| Browse            | View document metadata list                             |
| Organise          | Folders, collections, tags (as permitted)               |
| Classify          | Apply classification where available                    |
| Archive / restore | Lifecycle control (as permitted)                        |
| Search            | Find documents via platform Unified Search when indexed |

## Important limitations

Release **1.0.0** is **metadata-first**. Features such as file upload/download, OCR, in-app preview, and rich editing are **not** part of this release. See Known Limitations for the full list.

## Need help?

Contact your APZHUB administrator. Do not use external DMS admin consoles as the primary Documents experience.

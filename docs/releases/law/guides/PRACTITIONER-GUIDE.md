# APZ Law Platform 1.0.0 — Practitioner / User Guide

## Getting started

Sign in via APZHUB (Better Auth). Open the Law Platform workbench. Surfaces you see depend on your permissions.

## Everyday work

| Task                    | Where                      |
| ----------------------- | -------------------------- |
| Manage clients          | Clients                    |
| Open / work a matter    | Matters · matter workspace |
| File / manage documents | Documents                  |
| Track work              | Tasks · Time               |
| Schedule                | Calendar                   |
| Invoice                 | Billing                    |
| Trust funds             | Trust (authorised roles)   |
| Find records            | Legal search               |
| Overview                | Dashboard · Reports        |

## Important honesty notes (Release 1.0)

- Some UI surfaces may still show placeholder polish debt.
- Notifications/activity persist across reloads via platform durable session stores (OBS-LAW-02 closed — APZHUB-1.1-002).
- There is no Law Email inbox product in 1.0.
- Billing is in-Law; a shared Financial Engine is not part of this release.

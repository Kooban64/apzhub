## Overview

This release delivers the APZHUB **Platform Runtime** (`@apzhub/platform-runtime`): a coordinated runtime engine for manifest discovery, validation, dependency resolution, capability registration, lifecycle management, configuration, health monitoring, and orchestrated platform bootstrap.

---

## Highlights

### Platform Runtime package

New package `@apzhub/platform-runtime` with subsystems:

- **Manifest Engine** — YAML envelope validation
- **Discovery Engine** — filesystem manifest discovery
- **Dependency Graph** — resolution and cycle detection
- **Capability Registry** — in-memory capability index with read facade
- **Lifecycle Manager** — validated state transitions
- **Configuration Manager** — authoritative runtime configuration
- **Health Manager** — provider-based health aggregation
- **Runtime Orchestrator** — `Runtime.bootstrap()` startup coordination

### Public server API

```typescript
import { Runtime } from "@apzhub/platform-runtime/server";

await Runtime.bootstrap();
Runtime.getStatus();
Runtime.getDiagnostics();
Runtime.registry(); // PlatformRegistry facade
Runtime.health();
Runtime.configuration();
```

### Application integration

- `apps/web` bootstraps the Platform Runtime on server startup via instrumentation
- `/api/health` includes a runtime readiness summary (no Registry REST API)

### Scaffold manifests

- Activity Bar component manifest (TD-017)
- Default theme, platform registry service, registry-ready event


## Breaking changes

## Upgrade notes

1. Add `@apzhub/platform-runtime` dependency where server-side runtime access is required
2. Transpile `@apzhub/platform-runtime` in Next.js if importing directly
3. Call `Runtime.bootstrap()` once per process before using `Runtime.registry()`

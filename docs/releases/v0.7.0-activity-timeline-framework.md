## Executive summary

This release delivers the APZHUB **Activity & Timeline Framework** (`@apzhub/activity-timeline-framework`): unified Activity Registry and Timeline Registry, Event-to-Activity Mapper, Activity Service, Activity Presentation Layer, and Timeline Experiences integrated with the Context Panel Activity tab.

Authenticated shell integration wires activity providers behind `ActionWorkbenchShellProvider`. Timeline Experiences consume presentation view models through `useActivityTimelineExperienceDiagnostics()`. Successful action execution publishes `capability.action.executed` and surfaces activity items in parallel with notifications — no new execution pipeline.

## Implementation

### `@apzhub/activity-timeline-framework` package

| Component                    | Description                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| Activity Registry            | Bootstrap, validation, platform catalogue, server DTO map/filter                                       |
| Timeline Registry            | Scope descriptors (`timeline.personal`, team, workspace, system)                                       |
| Bootstrap                    | `bootstrapActivityRegistry()`, `bootstrapTimelineRegistry()`                                           |
| DTO hydration                | `filterActivityRegistryDto()`, `filterTimelineRegistryDto()`, `buildActivityTimelineHydrationBundle()` |
| DefaultEventToActivityMapper | Parallel Event Bus subscriber; never publishes                                                         |
| DefaultActivityService       | Session store, listActivities, queryTimeline, diagnostics                                              |
| Activity Presentation Layer  | View models, date grouping, relative timestamps                                                        |
| React providers              | `ActivityTimelineProvider`, `ActivityTimelineServiceProvider`, hooks                                   |

## Integration

### Application (`apps/web`)

- `createAppActivityTimelineContext()` — composition root with shared Event Bus
- `wireAppActivityTimeline()` — production mapper → service subscriber
- `loadActivityTimelineHydration()` — server permission-filtered bundle
- `ActionWorkbenchShellProvider` — Activity providers after Notification providers
- Health endpoint `activities` + `timelines` fields
- Developer diagnostics — `ActivityTimelineDiagnostics` (non-production)
- E2E test hooks — `__APZHUB_E2E__` when `NEXT_PUBLIC_E2E_TEST_HOOKS=true`

### DesktopShell flags

- `enableActivityTimeline` — feature gate
- `enableActivityTimelinePanel` — Context Panel Activity tab

### Capability manifest blocks

- `activities.types[]` — activity type registration (not `activity.types`)
- `activities.timelines[]` — timeline scope descriptors

## User-facing capabilities

Authenticated users on `/workspace/*` benefit from platform activity timeline infrastructure:

- **Context Panel Activity tab** — personal timeline with date-grouped items
- **Action-driven activity** — successful workbench actions appear after audit hook
- **Parallel notifications** — badge/panel unchanged; activity is independent
- **Health observability** — operators verify activity/timeline hydration via `/api/health`

Live auto-refresh, viewed/unread affordances, search/filter, and cross-session persistence are **not** implemented.

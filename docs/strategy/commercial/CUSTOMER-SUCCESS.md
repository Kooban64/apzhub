# APZHUB Customer Success Model

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20

---

## Goal

Customers achieve outcomes on certified surfaces and renew/expand without surprise from Known Limitations.

## Success stages

| Stage     | Outcome                                                                           |
| --------- | --------------------------------------------------------------------------------- |
| Deployed  | Platform 1.1.0 + agreed packages live                                             |
| Adopted   | Weekly active use of landed products                                              |
| Value     | Measurable ops/legal outcomes (tickets closed, time captured, matters progressed) |
| Expanded  | Additional modules / seats / edition uplift                                       |
| Advocated | Reference / case study (with honesty)                                             |

## Cadence

| Touch        | When                        |
| ------------ | --------------------------- |
| Kickoff      | Week 0                      |
| Health check | 30 / 60 / 90 days           |
| QBR          | Quarterly for Professional+ |
| Risk review  | When P1/P2 or adoption lag  |

## Support strategy (commercial)

| Tier             | Entitlement (commercial) | Ops delivery             |
| ---------------- | ------------------------ | ------------------------ |
| Standard         | Business hours L1/L2     | Operations Support Model |
| Premium          | Faster OLA / named CSM   | Ops + Customer Success   |
| Mission-critical | 24×7 P1 (contracted)     | Only if staffing exists  |

Do not promise Email delivery or Workflow execute in success plans.

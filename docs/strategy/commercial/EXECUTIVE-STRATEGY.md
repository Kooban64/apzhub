# APZHUB Executive Commercial Strategy

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20  
> **Baseline:** Platform **1.1.0** PRWL

---

## Vision to market

**APZOR** commercialises **APZHUB** as an Enterprise Operating Platform: one Workbench, many products, self-hosted first, engine brands masked — sold with honest **PRODUCTION_READY_WITH_LIMITATIONS** maturity.

## Strategic intent

| Intent              | Meaning                                                                          |
| ------------------- | -------------------------------------------------------------------------------- |
| From build to adopt | Engineering/ops/governance complete → commercial execution                       |
| Land then expand    | Start with suite or Law; expand modules when certified                           |
| Internal first      | APZOR/internal adoption proves ops + onboarding before aggressive external scale |
| Honesty wins        | Never sell Workflow execute, Email SoR, FIN-001, or Support realtime as GA       |

## Commercial model (summary)

| Element  | Model                                                                               |
| -------- | ----------------------------------------------------------------------------------- |
| Platform | APZHUB Platform **1.1.0** (subscription / support on software)                      |
| Products | Edition ladder (Community → Professional → Enterprise → Government / Partner / OEM) |
| Vertical | Law Platform as flagship pack                                                       |
| Services | Implementation, training, premium support                                           |
| Partners | MSP / OEM / referral                                                                |

## Target markets (priority)

1. Mid-market operations / professional services (Projects + Time + Support)
2. Legal practices / legal ops (Law + Time + Documents adjacency)
3. Regulated / government (Government edition packaging)
4. Partners / MSPs (Partner edition)

## Ideal customer profiles (ICP)

| ICP         | Signals                                                             | Offer                      |
| ----------- | ------------------------------------------------------------------- | -------------------------- |
| ICP-Ops     | 50–500 staff; fragmented PM/time/tickets; wants self-host           | Professional suite         |
| ICP-Legal   | Practice / legal dept; matter + time + docs; compliance sensitivity | Law pack + suite adjacency |
| ICP-Gov     | Sovereignty, audit, SSO depth                                       | Government edition         |
| ICP-Partner | Delivers IT to multiple clients                                     | Partner / MSP              |

## Success thesis

Within the revenue roadmap horizon: paid pilots → first Professional logos → Law pack wins → partner-assisted scale — without overselling PRWL gaps.

# APZHUB Implementation Methodology

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20  
> **Professional Services Strategy:** packaged delivery of this methodology

---

## Phases

```text
Discover → Design → Deploy → Configure → Integrate → Enable → Hypercare → Operate
```

| Phase     | Activities                                                 |
| --------- | ---------------------------------------------------------- |
| Discover  | ICP fit, KL disclosure, environment readiness, coexistence |
| Design    | Edition/package, identity, product enablement, RACI        |
| Deploy    | Staging then Production per Deployment Strategy            |
| Configure | Feature flags, roles, connector configs (secrets safe)     |
| Integrate | Adapters for selected engines; no Module→Engine shortcuts  |
| Enable    | Training + admin runbooks                                  |
| Hypercare | 2–4 weeks elevated support                                 |
| Operate   | Hand to Operations Framework + Customer Success            |

# APZHUB Commercial KPIs

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20  
> **Note:** Targets are directional; numeric quotas live out-of-band.

---

## Funnel KPIs

| KPI                | Definition                               |
| ------------------ | ---------------------------------------- |
| Qualified pipeline | ICP-fit opportunities past KL disclosure |
| Win rate           | Closed-won / closed opportunities        |
| Cycle time         | Qualify → Close                          |
| Pilot conversion   | Pilots → paid                            |
| Attach rate        | Services attach to subscription          |

## Product / adoption KPIs

| KPI                   | Definition                              |
| --------------------- | --------------------------------------- |
| WAU / seats activated | Weekly active vs licensed               |
| Module utilisation    | Landed modules with real usage          |
| Time-to-value         | Kickoff → first meaningful outcome      |
| Expansion             | Seat or package uplift within 12 months |

## Quality / risk KPIs

| KPI                      | Definition                                 |
| ------------------------ | ------------------------------------------ |
| KL surprise incidents    | Support tickets from oversold capabilities |
| Churn / logo loss        | Non-renewal                                |
| P1 commercial impact     | Sev-1 affecting paid customers             |
| Partner delivery defects | Partner-caused Production issues           |

## Operations linkage

Commercial KPIs must not conflict with Operations SLOs or force selling uncertified surfaces.

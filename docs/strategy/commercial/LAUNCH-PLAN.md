# APZHUB Launch Strategy, Pilot Programme & Customer Rollout

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20  
> **Baseline:** Platform **1.1.0** PRWL

## Launch strategy

| Wave | Name                | Intent                                  |
| ---- | ------------------- | --------------------------------------- |
| L0   | Internal Adoption   | Dogfood; prove ops + CS playbooks       |
| L1   | Supervised Pilot    | 1–3 logos; tight success criteria       |
| L2   | Controlled External | Professional packages; references       |
| L3   | Scale               | Partners + broader ICP; still KL-honest |

No “GA everything” launch. Sell certified surfaces only.

## Pilot programme

| Element   | Rule                                                             |
| --------- | ---------------------------------------------------------------- |
| Duration  | Typically 4–12 weeks                                             |
| Scope     | One package (prefer Starter or Law)                              |
| Success   | Adoption + outcome metrics (SUCCESS-MEASURES)                    |
| Exit      | Convert / expand / exit with learnings                           |
| Forbidden | Selling STOP capabilities as pilot “stretch goals” without Owner |

## Customer rollout plan

```text
Internal cohort → Pilot logos → Early Professional → Enterprise / Gov (assurance ready) → Partner channel
```

Product Roadmap Alignment: commercial waves only expand when Release Certification + Product Management editions allow; Release 1.2 not authorised by this programme.

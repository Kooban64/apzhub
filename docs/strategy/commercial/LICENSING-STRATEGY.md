# APZHUB Licensing Strategy (Execution)

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20  
> **Principles:** [PRODUCT-LICENSING.md](../../product-management/PRODUCT-LICENSING.md)

---

## Model

| Layer                     | License posture                                               |
| ------------------------- | ------------------------------------------------------------- |
| Backend engines           | OSS CE (Plane, Kimai, Zammad, …) — customer/host compliance   |
| APZHUB platform & modules | Commercial license (APZOR) per edition                        |
| Partner / OEM             | Separate agreement; white-label via Presentation Engine rules |
| Community                 | Evaluation / limited Production — no Enterprise SLA           |

## Execution rules

1. Never require Enterprise Edition of engines.
2. License grant does not imply entitlement metering software (not built).
3. Support entitlement follows support tier, not engine vendor support.
4. Government/OEM terms out-of-band; this doc frames only.

# APZHUB Customer Onboarding Process

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20

---

## Onboarding checklist

| #   | Activity                                            | Owner                        |
| --- | --------------------------------------------------- | ---------------------------- |
| 1   | Commercial handoff pack (SKU, edition, KL appendix) | Sales → CS/PS                |
| 2   | Environment readiness (Dev/Test/Staging/Prod)       | Environment Owner            |
| 3   | Identity / SSO / roles                              | Identity Service Owner       |
| 4   | Product enablement / provisioning                   | Platform Ops + Product Owner |
| 5   | Connector configuration (secrets safe)              | Integration owner            |
| 6   | Admin training                                      | Training                     |
| 7   | Pilot user cohort                                   | Customer Success             |
| 8   | Hypercare exit criteria                             | CS + Ops                     |
| 9   | Operate steady-state                                | Operations Framework         |

## Customer lifecycle (commercial)

```text
Prospect → Customer → Onboarded → Adopted → Expanded → Renewed / Churned
```

Churn risk signals: unused modules sold as GA; surprise KL; unsupported Email/execute expectations.

## Packaging rules

1. One platform codebase — packages are entitlement + services, not forks.
2. Include Platform **1.1.0** capabilities actually Accepted (Event Bus Attention foundation, Automation Foundation — honestly scoped).
3. Exclude STOP capabilities from package feature lists.
4. Map every SKU to edition matrix rows before quote.

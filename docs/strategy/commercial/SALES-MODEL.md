# APZHUB Sales and Pre-Sales Model

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20

---

## Sales process

```text
Lead → Qualify (ICP + KL) → Discover → Solution → Propose → Negotiate → Close → Hand to Onboarding
```

## Pre-sales process

| Step                     | Output                                   |
| ------------------------ | ---------------------------------------- |
| Discovery                | Pain, engines in use, hosting preference |
| Fit assessment           | Package + edition recommendation         |
| Demo                     | Brand-masked Workbench; honest non-goals |
| POC / Pilot criteria     | Success measures from SUCCESS-MEASURES   |
| Security/compliance pack | AuthZ, audit, SoR boundaries, PRWL       |
| Proposal                 | SKUs + services + limitations appendix   |

## Qualification kill criteria

- Requires Workflow execute as GA now
- Requires Email SoR / SMTP delivery as platform feature now
- Requires FIN-001 / accounting engine now
- Rejects self-hosted / demands unsupported SaaS metering

## Handoff

Closed-won package → Implementation Methodology kickoff + Customer Success owner.

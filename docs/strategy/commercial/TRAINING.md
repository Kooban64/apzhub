# APZHUB Training Strategy

> **Programme:** APZHUB-STRATEGY-001  
> **Date:** 2026-07-20

## Audiences

| Audience           | Focus                                       |
| ------------------ | ------------------------------------------- |
| End users          | Workbench navigation, product workflows     |
| Workspace admins   | Roles, prefs, enablement                    |
| Platform operators | Deploy, health, incidents (Operations docs) |
| Partners           | Delivery methodology + KL honesty           |
| Sales / CS         | Packaging, non-goals, demo scripts          |

## Curriculum pillars

1. **Platform literacy** — shell, permissions, SoR boundaries
2. **Product paths** — Projects / Time / Support / Docs / Law as sold
3. **Limitations** — Workflow execute, Email SoR, Support realtime, FIN-001
4. **Ops handoff** — where to look in Administration Workspace

## Delivery modes (planning)

Instructor-led · self-paced docs · partner enablement workshops · recorded demos (assets later).

Training materials beyond this strategy require a separate content programme.

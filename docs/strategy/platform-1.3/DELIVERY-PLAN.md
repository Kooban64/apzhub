# Delivery Plan — Platform 1.3

> **Programme:** APZHUB-PLAN-001  
> **Date:** 2026-07-22

## Principles

1. **Manifest / Delivery Standard first** — no skipped stages.
2. **One Owner Approval per engineering programme.**
3. **Architecture Freeze** — Module → Service → Connector → Engine.
4. **Integration SDK 1.0.0 remains frozen.**
5. **Respond fast, process async** for realtime/search/observe.
6. **Honesty** — update KL on every Acceptance.

## Definition of Ready (per ENG)

- Named Owner Approval
- Epic referenced
- Non-goals include STOP list
- Test/docs plan

## Definition of Done (per ENG)

- Platform Delivery Standard stages complete
- KL/registers updated
- No STOP surface opened

## After Owner Portfolio Acceptance

1. Owner selects Wave A first programme (recommended: ENG-001 or ENG-003).
2. Issue formal Owner Programme Approval for that ID only.
3. Do not batch-approve all ENG-001…011 without sequencing.

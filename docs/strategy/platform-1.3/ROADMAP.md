## Platform 1.3 — Operate, complete, connect

### Vision

Make Platform **1.2.0** honestly operable and connected: live Search, live Observe alerts, Support realtime, notification delivery (not Email SoR), Analytics embed, Workflow designer adjacency — **without** unlocking STOP gates.

### Objectives

1. Close PL12-KL-01/02/05 (Search drain, Observe live, Support realtime).
2. Deliver notification **delivery providers** without claiming Email SoR.
3. Advance Analytics to live embed / registry honesty.
4. Improve Workflow designer UX with Execute still gated.
5. Targeted Law / Time / Projects polish.
6. Ops/perf/SemVer hygiene as supporting epics.

### Major epics

See [EPICS.md](./EPICS.md) — P13-E01…P13-E12.

### Features (summary)

Support WS/SSE · Observe evaluation/delivery · Search composition drain · Notify providers · Analytics embed · Workflow designer · Law UX · Time approvals UI · Projects sprint/My Work · Perf baselines · Root SemVer alignment · Portfolio re-cert honesty.

### Dependencies

1.2.0 freeze intact · Integration SDK remains frozen · OPS go-live executed or accepted risk · Named Owner Approvals per engineering programme.

### Risks

Scope creep into Email/Execute/FIN · shared-host capacity · overclaiming GA · flaky E2E if quality not planned.

### Sequencing

Wave A (ops/connect): Search · Observe · Support realtime · Notify delivery  
Wave B (product connect): Analytics embed · Workflow designer  
Wave C (depth): Law/Time/Projects polish · Perf · SemVer  
Wave D (cert): Portfolio re-cert after Waves A–C

### Recommended release

**Platform 1.3.0** — PRWL+ (still not Email/Execute/FIN GA)

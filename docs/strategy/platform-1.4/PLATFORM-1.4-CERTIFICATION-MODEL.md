# Platform 1.4 Certification Model

## Retained lifecycle

```
Architecture Confirmation
  → ADR (where required)
  → Engineering
  → Owner Engineering Acceptance
  → Certification
  → Remediation if required
  → Re-certification
  → Owner Final Certification Acceptance
  → Release Closure
```

## CERT entry criteria (proposed)

- Every authorised epic Owner-accepted
- Every required ADR accepted
- Architecture compliance verified
- Quality gates executed honestly
- Security review complete
- Migration review complete
- API + event compatibility verified
- Operational documentation filed
- Known-limitations + risk review filed
- Evidence pack filed
- Owner acceptance trail complete

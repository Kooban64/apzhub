# Analytics Workbench — Known Limitations

1. **No live visual embed** — Dashboard Details shows registry metadata only; embed token HTTP is not exposed in ANALYTICS-005.
2. **In-memory registry MVP** — catalogue seed is not yet Postgres SoR.
3. **Search** — catalogue client-side filter; no dedicated Analytics Search Provider / semantic search.
4. **APZ Analytics commercial packaging** — Workbench module only; SemVer product release pack not authorised here.
5. **Exclusions remain** — AI analytics, predictive analytics, external BI, custom SQL builders.

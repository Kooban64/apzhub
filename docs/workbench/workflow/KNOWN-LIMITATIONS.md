# Workflow Workbench — Known Limitations

> **Programme:** APZHUB-PLATFORM-WORKFLOW-006

1. **Search** — definition catalogue search via Workflow HTTP `query` parameter; not a Platform Search Provider registration.
2. **Schedule detail** — loaded from schedule list (no dedicated GET-by-id HTTP resource).
3. **Provider execute** — may remain limited per CERTIFIED_FOUNDATION; diagnostics surface readiness honestly.
4. **Commercial APZ Workflow** — product packaging / designer / AI features not included.
5. **In-memory runtime** — depends on HTTP/services bootstrap mode for runtime persistence.

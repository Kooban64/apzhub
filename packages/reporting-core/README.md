# @apzhub/reporting-core

APZHUB Platform Reporting engine (APZREPORT-001).

Template binding, six output providers, and `createPlatformReportingService`.

Depends only on `@apzhub/reporting-contracts`. Products supply catalogues and persistence ports.

See [Platform Reporting Developer Guide](../../docs/developer/APZHUB-Platform-Reporting-Developer-Guide.md).

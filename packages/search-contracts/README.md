# `@apzhub/search-contracts`

Canonical APZHUB Platform Search contracts (APZSEARCH-001).

## Scope

- Canonical query / hit / index / diagnostics models
- Vendor-neutral provider interfaces (no implementations)
- Product adapter contracts (no implementations)
- Platform search service interfaces (no execution)
- `search.*` permissions

## Out of scope

HTTP · Workbench · OpenSearch/Elasticsearch/Meilisearch/Typesense/Postgres FTS · indexing engines · OCR · AI · vector/semantic search · Event Bus · workers
